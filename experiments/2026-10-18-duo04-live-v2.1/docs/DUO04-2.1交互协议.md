# DUO04-LIVE 2.1 交互接口

沿用 `/api/v1/commands`、随机令牌、任务编号和共享串口队列；GUI、CLI和Agent使用同一入口。旧固件不支持时明确失败，不静默模拟成功。命令失败或应答超时不重发击发；忙响应只在明确没有执行时沿用原队列策略。

| Agent命令 | 参数 | 用途 |
|---|---|---|
| `ui.action` | `action`字符串 | `rotate_left`、`rotate_right`、`confirm`、`back`、`key0`、`key0_long`、`key1`、`key2`、`key2_long`、`menu`、`diagnostic`、`stop` |
| `lesson.configure` | `source`: `imu`/`mouse`；`lesson`:0/1/2 | 先停止，进入教学，选择左手/右手/交替练习；不自动开始 |
| `lesson.control` | `action`: `start`/`pause`/`resume`/`stop`/`restart` | 板上控制练习；start/restart清零重来，pause/resume保留进度，stop清声音和反馈 |

UART命令十进制61：一个字节的UI动作，依上表顺序编码0～11；62：来源0/1、练习0～2共两个字节；63：控制动作stop/start/pause/resume/restart编码0～4共一个字节。字段仍受TangLab帧CRC保护。板载停止优先。

原命令60参数写入兼容；增加字段23教学来源、25单手归中（0左1右）、27教学控制、28单手复位。复位按钮在菜单中二次确认，直接API命令由调用者明确发起。旧字段21仍表示双手归中请求。

状态类型136新增格式版本7、256字节；前240字节兼容版本6。字节240操作手、241菜单层级、242分组、243项目、244教学来源、245反馈（0无1正确2错误）、246反馈手、247反馈区、248～249判题序号、250提示码、251归中状态（0无1等待2完成3失败）、252完成标志、253暂停/停止标志、254～255 UI操作序号。多字节小端。

菜单层级0关闭、1快捷、2分组、3选项、4编辑、5确认；分组0左手、1右手、2音效、3表达、4教学、5系统。按音符编号计分，反馈阶段目标保持到绿色结束；正确反馈期间的其他击发不计下一题。

API在ACK后还等待对应板上状态：UI操作序号、参数修订号与教学条件；返回`accepted`不宣称声音或显示器实测通过。新增能力`interaction_v21`，旧版仍可使用原有四音色与抓取。

鼠标教学沿用`duo.select/duo.strike`，但要求七音布局、C4（octave=0）、模式2且来源mouse。鼠标和IMU事件互斥；传感器教学不能借鼠标击发跳题。`duo.configure`代表自由鼠标演奏，可能切离教学；教学使用专用命令。

正弦校准、采样、声音参数及既有接口继续保留。`duo.configure`可选`octave_codes`用于2.1持久化左右八度（0=C4、1=C5、2=C2、3=C3），不改变原有调用方式。
