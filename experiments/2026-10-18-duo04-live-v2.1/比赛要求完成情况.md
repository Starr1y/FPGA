# 比赛要求完成情况：DUO04-LIVE 2.1

依据此前按《高云.pdf》选题二整理的[2.0逐项要求表](../2026-10-18-duo04-live-v2.0/比赛要求完成情况.md)。2.1是交互升级，不能沿用2.0的实现报告宣布本版时序通过。

| 要求 | 当前实现 | 剩余验收 |
|---|---|---|
| 基础：至少2个独立演奏维度 | 保留双IMU选区、击发、力度和姿态表情；新增明确操作手、归中状态和来源互斥 | 两颗真实IMU的稳定选区、归中、防误触及独立维度演奏 |
| 基础：HDL实时合成、控制到模拟输出≤10ms | 保留32声部、四音色、ADSR、混音和PT8211，PC不生成乐器PCM | 用外部仪器测完整延迟，串口往返或数字仿真不能替代 |
| 基础：≥4独立可闻复音 | 保留左右各16声部与监测能力 | 实物四路及32路可闻复音、音准、尾音、噪声和削波检查 |
| 拓展：≥32复音及并行能力 | 保留2.0合成结构 | 新版综合布线资源与时序、最坏负载长期实测 |
| 拓展：多维表情、多音色与硬件音效 | 四音色、力度/姿态、可选滑音颤音和音效保持 | 真实控制独立性、音色听感、效果质量及持续时间实测 |
| 拓展：确定性低延迟与实时视听 | HDMI双扇区、菜单、教学反馈；GUI波形和FFT | ≤5ms及最坏抖动未测；PC频谱不计作FPGA频谱；HDMI实物验证 |
| 拓展：脱机LED曲目指引等 | 新增双扇区高亮、正确闪亮后推进、错击提示；EC11与按键脱机菜单 | **实体LED指引未完成**，HDMI不替代该项；节拍评分、手机无线、在线曲谱和作品录音仍未实现 |

本版已通过数字检查和本机EXE模拟检查；未综合、未布局布线、未生成新版.fs、未上板。PR1014仍未闭环。保留上一版成果及其历史证据，不覆盖、不升级历史结论。

建议验证顺序：生成本版位流并查时序/时钟报告 → 串口握手重连和HDMI → 虚拟按键/编码器 → 鼠标教学 → 真实按键/EC11和双IMU → 多声部与音色 → 外部仪器延迟 → 实体LED等剩余拓展。
