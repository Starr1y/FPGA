# DUO04-LIVE 2.1：按键、编码器与双扇区教学

在2.0基础上保留四音色、32声部、48kHz、音频输出与采样链路；新增快捷按键、分组编码器菜单、虚拟控制入口，以及鼠标/IMU两种来源的板上教学判题。

打开 `tanglab_duo04.gprj`，顶层 `top_duo04`，138K C器件，输入50MHz。综合、布局布线和下载由用户执行；本目录没有新版 `.fs`，不能使用旧2.0位流验收2.1。未修改PLL/时钟约束，PR1014仍待实际实现检查，没有用假路径掩盖。

- [接线与操作指南](脱机演奏与教学指南.txt)
- [用户编译后的只读报告检查](check_implementation.py)
- 本轮测试是 `tb_ui21_controls`、`tb_ui21_stop`、`tb_ui21_encoder`、`tb_ui21_lesson`、`tb_ui21_uart`、`tb_ui21_panel`。继承TB不自动代表本轮通过。
- `validation/` 汇总实际通过项；最终源码未执行的综合/布线/实物测试单列。

教学沿用演奏双扇区与唱名：金色目标、青色预选、绿色正确250ms、红色错误180ms；正确反馈结束才推进。暂停保留进度，完成后不自动循环。KEY0归中、KEY1音色、KEY2切手；KEY0+KEY2稳定80ms停止。编码器旋转调音量，短按打开快捷菜单；设置分组，复位需确认。详见指南与 `操作图解.md`。

在配置好Vivado命令工具的终端执行：

```powershell
python run_regression.py D:/你的测试输出目录
python check_implementation.py
```

前者仅运行数字仿真；后者只读你生成的报告，未布线会返回NOT RUN。仿真不替代实体IMU、编码器、HDMI、模拟音质、总延迟或时序验收。实体LED教学未实现。

拨弦每声部1024×16位，32声部逻辑存储512Kbit；布局通常至少按32个1K×18存储块组织，具体以综合报告为准。分数延迟用共享2048项倒数ROM插值，补偿反馈平均滤波的半采样延迟；不做每声部大除法器。琴弦存储按分时单读/单写组织，避免三端口推断。

音符映射沿用MIDI36～89。开关滑音会影响单手复音行为；左和弦不启用左滑音。脱机时关闭电脑不会停止演奏，KEY2始终可以静音。

保留原项目的第三方来源和许可证。新增面板字形来自本机已有Noto Serif SC（SIL OFL 1.1），没有分发Windows字体。`generate_panel.py` 可用同一字体重建；`panel-font.json`记录字体文件SHA256。
