TangLab / DUO04-LIVE 2.1 按键、编码器与双扇区教学
2026-10-18；本版需要重新编译、布局布线并下载新工程。
保留2.0工程与.fs；2.0位流不能验证2.1新增入口。当前包不附新版.fs。

一、先开始鼠标与HDMI测试（不需要连接IMU、编码器）
1. 打开 fpga/duo04-ui21/tanglab_duo04.gprj，顶层top_duo04，138K C版器件。
   输入时钟50MHz。保持工程目录、ROM和impl中的IDE配置完整；你自行综合和布局布线。
   新.fs生成在本工程impl/pnr/tanglab_duo04.fs；用Programmer做SRAM下载。
   PR1014仍需看你生成的最终报告；不因仿真通过认定时钟警告消除。
2. 断电连接HDMI、3.5mm耳机或有源音箱AUX，音箱单独供电。不要把2pin功放输出接AUX。
   板卡沿用已确认的12V供电；数据线接DEBUG-USB2。上电后先松开全部按键。
   首轮不要带电插拔HDMI，以便排除已有USB/HDMI关联故障。
3. 运行本目录TangLab.exe，选择实际枚举的COM、921600，点击连接FPGA。
   状态应为DUO04-LIVE 2.1。显示2.0则说明下载的仍是旧位流；新入口会禁用。
4. 第08页可用旋钮−/＋、确认、返回、KEY0/1/2、菜单、诊断和停止按钮操作HDMI。
   所有操作发给FPGA，页面与参数以板上状态读回为准，不是在电脑假画一个菜单。
5. 若测试自由演奏，选择“电脑鼠标调试”，切换并静音；调整左右音色等后开始鼠标测试。
   若测试教学，选“鼠标教学测试”和一组练习，点“应用练习与来源（先停止）”，再点“开始”。
   此时七音C4布局，按下方金色目标区击发；不要再按“开始鼠标测试”，它会切换自由演奏模式。
6. 教学正确时原目标绿色闪亮约250ms，然后下一目标高亮；错手/错音区域红色约180ms，目标不变。
   绿色反馈期间的击发会发声，但不用于下一题，也不缓存到下一题。每个目标都需要新的击发。
   同一判题状态同时显示在HDMI和上位机；窗口刷新可能比板上反馈稍晚。
7. “暂停”保留进度及已判对的反馈阶段；“继续”接着练；“停止”清理声音与反馈，保留已完成进度。
   “重新开始”从第1题开始。完成16题后不会自动循环；编码器快捷菜单的开始项会重来，也可在教学设置选择重新开始并确认。退出教学切换其他演奏模式时，恢复进入前的音阶、八度和和弦，保持静音。
8. 共享波形面板支持跨页面观察32声部状态、最多4路声部PCM及输出波形。
   连续监测/击发同步抓取互斥；512/2048点均为完整分段采集，段间存在空档，不是无丢样音频流。
   暂停、游标、缩放、FFT幅相、CSV、记录回放仍保留。导出和记录在原对应页面操作。

二、板载按键速查（按PCB丝印）
KEY0=AA13，KEY1=Y12，KEY2=AB13；reset_key=F4是独立复位，不作为菜单快捷键。
演奏/教学主画面：
  KEY0短按           当前操作手归中；看等待/完成/失败，不把请求已发送当归中成功。
  KEY0长按1.5秒      当前手七音→五音→十二音；教学模式锁定音阶并提示。
  KEY1短按           当前手钢琴→马林巴→电钢琴→拨弦。
  KEY2短按           左/右操作手切换；画面亮线标出当前手。
  KEY2长按1.5秒      打开当前手设置，不直接复位IMU。
  KEY0+KEY1短按      打开/关闭设置菜单，必须全部松开。
  KEY1+KEY2短按      演奏/诊断切换；教学进度不变。
  KEY0+KEY2          稳定按下约80ms立即停止；不是静音开关，再按不会自动恢复。
菜单中：KEY1下一项/增加，KEY2上一项/减少，KEY0确认，KEY0长按返回一级。
组合键不会顺带执行各个单键。上电按住的键必须先松开，不自动触发动作。
不使用三键组合和按住KEY1临时表情；表情、和弦和音效使用明确菜单。

三、编码器与接线
普通3.3V兼容GVABS模块，断电连接：
  G -> J13.12 / GND
  V -> J9.1 或 J9.2 / 3.3V
  A -> J13.1 / E14
  B -> J13.2 / E13
  S -> J13.3 / C15，按下低有效
J13.11是5V，不接V或信号。按方焊盘/PCB的1脚定位，不凭照片左右猜编号。
若模块只标5V或内部有特殊电路，先核对模块资料。裸机械触点不需要VCC。
旋转方向反了，断电后交换A/B。默认每格4个合法边沿，非法跳变计数可诊断。
  主画面旋转：每格调总音量4/256，画面显示百分比和音量条，约1.5秒后收起。
  短按：先打开快捷菜单，再次确认才开始/暂停或切换页面。
  菜单旋转：选择选项；短按进入编辑，再旋转调值；短按确认退出编辑。
  长按约800ms：返回一级，松开不会再执行短按。
设置分左手、右手、音效、表达、教学、系统；保持时间单位ms，释音档位0/1/2=0.2/0.5/1.5秒。
更改数值立即生效；复位IMU须再次确认。总音量、模式、已生效状态与上位机共用一份板上参数。
若你在电脑上尚有未应用编辑，期间又使用按键改了参数，程序会阻止旧编辑覆盖；点“读取板上参数”放弃草稿后再改。

四、真实双IMU与脱机教学
沿用当前已核对的两条独立I²C总线；本版不是旧SPI/UART测试工程。
  左：SCL J13.38/E19，SDA J13.40/C18，INT J13.28/E16，RST J13.36/D20。
  右：SCL J13.37/D19，SDA J13.39/C19，INT J13.31/E17，RST J13.32/F16。
已确认GY模块的VCC_3V3接3.3V，GND共地；PS1/PS0=00，AD0=0，各独立总线地址0x4A。
CS按该GY模块已核对的I²C接法接地；F16现在是右手RST，不能保留旧SPI片选接法。
先用单颗健康模块，再接双手。教学来源选“IMU脱机教学”，应用来源，等在线后归中并开始。
归中时保持手稳定；没有在线/合格数据不能靠点击归中就变成完成。归中失败先检查总线、地址、供电、报告质量。
教学目标手离线会暂停并保留进度；恢复在线并归中后明确“继续”。不自动恢复发声。
IMU脱机教学不需要PC心跳；关闭上位机不应成为脱机停止方式，请用停止组合键。
鼠标教学则保留PC心跳、外部失焦和断连保护。软件内部浮动波形面板不会视为外部失焦。

五、练习、声音和版本边界
三组各16步：左手、右手、双手交替；七音C4单音判题，暂不做节拍评分。
金色目标不等于当前手的青色预选；移到目标只是预选，实际击发正确才推进。
保持时间从实际起音算，到点松键，之后有释音；自然衰减独立，不能理解成全过程等响。
四音色与32声部音频运算链路沿用2.0，本轮不通过改音色、音量保护或采样率来实现界面变化。
HDMI教学不冒充赛题的实体LED曲目指引；总延迟和实物音质仍需仪器/人工确认。
这是源码、数字仿真和软件交付；本轮没有综合、布局布线或下载。你完成编译后检查时序、资源和PR1014。

六、Agent与分享
第07页手动开启本机接口，仅127.0.0.1，随机令牌。TangLabCtl.exe无需Python。
示例（在程序文件夹终端；实际连接COM自行选择，不写死）：
  .\TangLabCtl.exe status
  .\TangLabCtl.exe run ui.action --file .\examples\菜单.json
PowerShell中推荐参数文件方式，避免引号转义差异：
  .\TangLabCtl.exe run lesson.configure --file .\examples\鼠标教学.json
  .\TangLabCtl.exe run lesson.control --file .\examples\开始教学.json
  .\TangLabCtl.exe run ui.action --file .\examples\停止.json
详细接口及二进制字段见docs/DUO04-2.1交互协议.md。应答与状态读回完成，不等于实物听音验收通过。
分享时发送整个ZIP，接收者完整解压运行EXE，无需Python；驱动、Gowin工具及许可证另备。
不能只发送TangLab.exe。不要分享.agent-session.json、个人记录或EDA许可证。
