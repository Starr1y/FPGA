## 本版变更

保留钢琴、马林巴、电钢琴、拨弦、32声部、48kHz左右独立音频，以及共享波形面板、真实PCM选路、512/2048点分段抓取、频谱、记录与回放。音频DSP与CST/SDC沿用2.0，本轮不宣称提升音质或时序。

按键处理归中、音色、操作手和安全停止；EC11处理菜单与数值。板载输入、GUI虚拟按键和Agent共用板上参数及状态读回，避免PC旧配置覆盖本地修改。演奏画面旋转编码器每格调音量4/256，短按快捷菜单，长按约800ms返回；菜单中旋转选择、短按确认。

| 操作 | 功能 |
|---|---|
| KEY0短按／长按1.5秒 | 当前手归中／切7、5、12音区（教学中锁定换区） |
| KEY1短按 | 当前手轮换四音色 |
| KEY2短按／长按1.5秒 | 切操作手／当前手设置 |
| KEY0＋KEY1短按 | 设置菜单开关 |
| KEY1＋KEY2短按 | 演奏与诊断页切换 |
| KEY0＋KEY2稳定按下约80ms | 全局停止并清理声音，不自动恢复 |

普通动作在合格松键执行，组合键吞掉单键；上电按住须先释放。菜单内KEY1下一项/增加、KEY2上一项/减少、KEY0确认，KEY0长按返回。停止组合始终优先。

教学复用双扇区：金色目标、独立预选边框、正确绿色约250ms后推进、错误红色约180ms且不推进。三组七音C4练习支持真实IMU或纯鼠标互斥来源；板上判题，不在PC自行判对。暂停保留进度，完成不自动循环。进入教学暂存原布局、八度及和弦，退出恢复并保持停止。教学目标手IMU断连会暂停。

第08页可虚拟操作按键、编码器及教学，状态以板上读回为准；无需连接编码器也可测试HDMI。鼠标来源保留心跳与外部失焦保护，脱机IMU来源不依赖PC心跳。实体LED曲目指引尚未实现。

## 构建与验证边界

上位机源码在 `source/`，在Windows Python虚拟环境安装 `source/requirements-lock.txt` 后运行 `python source/build_ui21.py`。脚本只构建软件，不调用EDA；依赖许可位于 `licenses/`。运行 `fpga/duo04-ui21/run_regression.py` 可执行所列XSim检查，需已安装对应工具，详情见工程README。

已完成六组RTL数字检查、九幅直接栅格渲染、主机协议解析及最终EXE/CLI模拟联测。串口数字集成78帧CRC错误0；这不是实物串口零错承诺。教学单位测试使用缩放时钟；顶层测试缩短反馈等待。IMU在解码边界注入，不代替真实I²C验证；TANG_SIM不验证物理PLL/TMDS。EXE仅在本机检查，未冒充其他电脑实测。
