# GEST26 稳定版（保留基线）与 TangLab 2.6

按用户要求标记为“稳定版”，用于固定并保留26版功能基线。该名称不代表最新源码已通过实现或整机验收。

## 验证边界
- 保留四音色、32声部、双IMU、鼠标测试、教学、HDMI与采样监测。未包含27版曲谱上传。
- 配套上位机为TangLab 手势稳定2.6。
- 既有RTL/软件验证记录随工程保留。2026-10-29本机后来重跑的26版PNR报告存在PR0004、10893条未布通网络；不能声称当前源码时序/布线通过。
- 不提供已验证26版.fs。综合、布线与烧录由用户完成；既有报告只作证据。实物掉线、击发和音准仍需验证。

## 使用
1. Release下载TangLab-2.6-stable-portable.zip，完整解压后运行TangLab.exe，无需Python；驱动/Gowin另装。
2. IDE打开fpga/tanglab_duo04_stable26.gprj，先综合再布局布线，检查setup/hold、PR1014和资源。
3. 连接方式和静音测试见fpga/README.md及接线与测试指南；使用相匹配固件。

原有仓库工程未覆盖。源码在fpga和host-source，便携程序在Release；不包含个人记录、会话令牌或Gowin许可证。
