# 上位机与脱机操作指南

## 快速开始：不用IMU的鼠标演奏

1. 先按接线指南下载本次.fs，再运行解压后的 `TangLab.exe`，选择实际COM、921600，点击连接FPGA。看设备名，应为DUO04-LIVE2.0。
2. 打开08“鼠标音区测试”，左右各选钢琴/马林巴/电钢琴/拨弦、7/5/12音区、C2/C3/C4/C5八度和力度。先用低总音量、音效旁路。
3. 点击“开始鼠标测试”（内部会切到电脑模式并清理旧声音），等设备应答。移动仅预选，左键每按下一次击发一次；双击两次，按住不连发，离开扇区取消预选。
4. 调参数后点击“应用音区参数”。保持时间表示从板上实际起音到松键，之后还有释音；钢琴/马林巴/拨弦自身会自然变轻。钢琴主体保持只作用于钢琴，不会延长按键保持时长。
5. 可测试双旋律或左和弦右旋律；左和弦不启用左滑音。颤音/滑音可分别开关；独立正弦不受这些演奏效果影响。
6. 点击停止测试，或KEY2全局静音。电脑模式外部失焦/通信超时有停止保护；应用内部浮动波形面板不是外部失焦。不要在测试过程中另开串口助手抢占端口。

## 所有主要页面与监测

| 页面/功能 | 当前DUO04用途 |
|---|---|
| 01音频示波器 | 单次2048点、连续512/2048点，最新一段/滚动历史、跟随最新、暂停、清空、缩放、各路时间/幅值游标、CSV。分段采集有空档，不能当成无丢失连续流 |
| 02声部与包络 | 旧四声部固件控制；DUO04使用08页四音色参数与32声部监测，不能把五路总线误认作四个声部 |
| 03 IMU三接口 | 旧SPI/UART测试固件入口，不用于DUO04双I²C配置；本版传感器先看08页在线状态与实际事件 |
| 04延迟与记录 | 记录原始通信/状态并回放；总线、处理、PC往返测点不同，不等于动作到模拟声音总延迟 |
| 05 Gowin工程 | 手动选择本快照fpga/tanglab_duo04.gprj和实际Gowin路径，再调用综合/布局布线、查看日志；不要沿用默认旧四声部工程路径。Programmer下载由用户完成 |
| 06频谱分析 | 选择五路总线通道看幅度/相位谱；FFT只使用最新完整片段。512点分辨率93.75Hz，2048点23.4375Hz，不能仅凭低音峰所在格点判断音准 |
| 07 Agent调试 | 手动开启本机接口，随机令牌，只监听127.0.0.1；复制会话信息给可信本机工具，停止服务后令牌失效，禁止分享会话文件 |
| 08鼠标音区测试 | 双扇区、四音色、音量/音效/保持/释音/表达、模式/教学/归中控制，以及独立正弦校准 |
| 共享波形面板 | 跨页显示32声部活动/音符/包络；最多选4个声部看真实板内PCM，并看效果后左右输出。可停靠/浮动、暂停、缩放及导出 |

五路总线固定为干声左、干声右、效果后左、效果后右、效果后左右平均；额外声部帧与总线通过同次抓取编号关联，缺包不覆盖上一段有效波形。
连续监测与击发同步抓取互斥；同步抓取繁忙时新击发仍可能发声，但该次抓取会明确跳过。暂停绘图冻结显示/分析，后台有限历史仍可更新；清空波形停止自动抓取并屏蔽在途旧图。
时间游标读两点及差值/对应频率，幅值游标读两点幅值差；右键为中文菜单。分栏与叠加保留独立游标状态。FFT幅度为dBFS、相位为度；相位以片段起点为参考，不是接口延迟。

## 独立正弦检查音箱/底噪

08页选择1000Hz、−30dBFS、双声道开始，再逐步调电平。范围20–10000Hz、−60至−6dBFS，持续到停止；绕过音色/音效/响度补偿，不占演奏声部。与鼠标演奏互斥，约5ms渐变启停。先检查单边，再检查双边；换有源音箱后从低音量开始。
数字谱干净不证明模拟输出无底噪；音箱、供电、线材和接地需独立对照。

## 脱机与HDMI菜单

上电静音，模式0脱机、1电脑鼠标、2逐音教学；切换先清理旧声音。模式0/2不依赖PC心跳，关闭上位机不会自动停止脱机演奏；使用EC11停止或KEY2静音。参数不保存到Flash。

- 演奏页：短按开始/停止；旋转进入设置或状态，长按回演奏。
- 设置页：旋转选项，短按进入编辑，旋转改值，再短按退出编辑；长按返回。
- 教学页：短按开始/重来。设置中选择左手、右手或双手交替练习。
- 状态页：短按请求双手归中，双手保持静止；请求提交不等于传感器归中完成。

**没有编码器时的限制：**08页可改变模式与音色参数，但当前没有虚拟编码器/HDMI直接切页命令。不能把上位机页签切换当成HDMI换页。逐音教学使用真实IMU事件，鼠标演奏模式不能直接推进教学；这些远程测试入口列为下一步。

## 逐音等待教学

三组各16步，C4七音、单音；屏幕提示目标手、音区与MIDI音符。正确手击发正确音才推进，错击计数但不前进；完成后重新短按再练。不做节拍评分，没有实体LED灯带教学，不将HDMI提示替代赛题LED专项。

## Agent与命令行

接口开启后在程序文件夹运行 `TangLabCtl.exe status`、`capabilities`、`ports`；它自动读取本地会话文件，不在命令里硬编码令牌或COM。

```powershell
.\TangLabCtl.exe status
.\TangLabCtl.exe run instrument.set --file .\examples\offline.json
.\TangLabCtl.exe run duo.configure --file .\examples\mouse.json
.\TangLabCtl.exe run instrument.set --file .\examples\lesson.json
.\TangLabCtl.exe run duo.stop
```

examples里的开始命令会改变运行模式；先确认连接正确且输出音量低。命令输出“设备接受”不等于采样完成或听音通过，长任务应等待任务完成。更多现有API见host/docs/agent调试接口说明.md，DUO04新增instrument.set和instrument.demo；后者始终是模拟。
Codex/Claude可使用提示词：“读取TangLabCtl状态和能力，只用上位机持有的串口进行DUO04测试，先保存参数、低音量、逐项记录，区分模拟/设备应答/采样完成，结束停止校准与鼠标声音；不要自行烧录或切换驱动。”

## 重建与分享

直接使用portable ZIP无需Python；发给别人时发送整个ZIP或整个解压目录。开发者从host建立Windows64位Python虚拟环境，安装requirements-lock.txt，使用build_exe.py重建；可用TANGLAB_BUILD_DIR指定本次构建目录，不修改全局PATH/TEMP。XSim测试脚本中的工具路径应改为开发者自己的Vivado安装位置。
不要把Agent会话令牌、个人记录或Gowin许可证加入仓库；已有运行包附第三方许可。修改RTL后必须重新编译并核对新.fs与报告，下载仍由用户执行。
