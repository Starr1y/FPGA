# DUO04-LIVE 2.0 FPGA工程

打开 `tanglab_duo04.gprj`，顶层 `top_duo04`，器件 `GW5AST-LV138PG484AC1/I0`。
参考输入50MHz，PLL输出系统50MHz、像素25MHz、串行125MHz；音频48kHz、左右各16声部。

- 用户本次编译位流：[bitstream/tanglab_duo04.fs](bitstream/tanglab_duo04.fs)。
- [构建与位流元数据](FIRMWARE.json)、[当前实现报告](reports/pnr/)、[数字验证](validation/)。
- [接线与上板指南](../接线与上板指南.md)、[功能操作指南](../上位机与脱机操作指南.md)。

setup/hold零违例，最差setup余量+0.299ns；PR1014仍保留，不能据生成位流认定时钟警告已经消除。
`clk_d`在网表中仅是输入缓冲到PLL参考端，系统寄存器使用PLL输出；这不证明参考路径的抖动已实测合格。
提供的.fs用于逐项联调，不标为比赛整机验收完成。新修改必须重新综合、布线并重新检查报告。

四音色为钢琴、马林巴、电钢琴、反馈拨弦，全部由硬件实时运算。拨弦每声部1024×16位，总逻辑存储512Kbit；实际全工程BSRAM132/340。
保持时间从实际起音计数，到点松键，随后进入释音；自然衰减独立，不承诺保持期间等响。
项目ROM使用相对路径 `rtl/`；请保持目录完整。字体来源和OFL全文随工程保留。
