DUO04-LIVE 2.0：四音色、EC11与HDMI逐音教学
硬件：Tang Mega 138K C / NEO Dock，50 MHz参考时钟。
本目录是独立新工程；不要用旧1.3/1.4位流替代。编译与位流状态见交付状态.txt；只有最终检查通过的.fs才用于烧录。下载仍由你操作。

一、先准备和编译
1. 首先保留旧版工程与可用.fs。首次测试只接板卡、DEBUG-USB2和HDMI。
2. Gowin IDE打开tanglab_duo04.gprj，顶层top_duo04，器件GW5AST-LV138PG484AC1/I0。
3. 参考输入必须为50 MHz；本版同一个PLL产生系统50 MHz、像素25 MHz、串行125 MHz。
4. 最终版需你重新综合、布局布线。当前不提供合格.fs；成功后结果位于impl/pnr/tanglab_duo04.fs。
5. 旧实现仍有PR1014和setup违例，最终源码已做路径与时钟结构调整，效果尚待重新布线确认。核对setup/hold、未约束路径、时钟网络和PR1014。运行python check_implementation.py可读报告，但脚本通过不代替人工核对。
6. 用官方Programmer执行SRAM下载。成功后应看到新版界面，默认静音。SRAM断电失效；不要带电改线来保留程序。

二、断电接EC11
适用于裸EC11或已确认3.3 V兼容的模块。A/B及SW为输入、内部上拉，公共端接地。
EC11 A / 模块CLK：J13.1 → FPGA E14
EC11 B / 模块DT ：J13.2 → FPGA E13
按键SW          ：J13.3 → FPGA C15
公共端/按键地   ：J13.12 → GND
J13为SDRAM0长排针，针号依据既有NEO Rev1.4原理图追踪，不按照片左右猜方向。
J13.11是5 V，不要接入这些信号。裸触点不需要VCC；带供电模块先核对其电路，不能输出5 V。
默认每定位4个合法边沿；若方向反了，断电交换A/B；若每格两次/半次，核对编码器规格再改EDGES_PER_STEP。
不能同时接占用J13相同信号的SDRAM或其他驱动器。

三、双IMU接线：本版为两路独立I2C，不是旧SPI接法
模块信号             左手J13针/FPGA       右手J13针/FPGA
SCL/SCK/RX           J13.38 / E19         J13.37 / D19
SDA/MISO/TX          J13.40 / C18         J13.39 / C19
INT                  J13.28 / E16         J13.31 / E17
RST                  J13.36 / D20         J13.32 / F16
VCC_3V3：接实际已核实的3.3 V供电；GND共地。J13.11不能当3.3 V使用。
PS1=0、PS0=0选择I2C，AD0=0使地址0x4A；两路物理总线独立，所以地址可以相同。
CS沿用已有模块I2C接法；不得继续按旧SPI约束把第一颗CS接到F16，那已是右手RST。
SCL/SDA及RST依赖正确3.3 V上拉，模块已有上拉时先确认阻值，不盲目并联。
整体断电接线。上电时可能运行Flash中的旧程序，应先核对启动来源和引脚用途；不能把下载过SRAM当成掉电后仍有效。
手动开始/停止不是供电检测或电气隔离。未确认电源与接线前不要接入模块。

四、脱离上位机操作
演奏页：旋转到设置/教学/状态页；短按开始或停止演奏；长按返回演奏页。
设置页：旋转逐项选参数，短按进入编辑，旋转改值，再短按确认；长按返回。
教学页：短按开始或重新练习。状态页：短按给双手归中，归中时双手静止。
KEY2合格短按执行全局静音，不需要电脑。旋转/短按不会替代紧急静音。
模式0=脱机演奏，1=电脑鼠标调试，2=逐音教学。切换模式先静音，再开始。
设置依次为：模式、左右音色、左右音阶、左右八度、左和弦、音量、音效、湿度、左右保持毫秒、左右释音档、左右颤音、左右滑音、教学曲目。
音色0钢琴、1马林巴、2电钢琴、3拨弦；音阶0七音、1五音、2十二音。
八度编码0=C4基准、1高一组、2低两组(C2)、3低一组(C3)。拨弦支持当前MIDI36～89映射。
释音0约0.2 s、1约0.5 s、2约1.5 s。每个已起音音符固定自己的保持时长。
脱机菜单中的颤音开关使用5.5 Hz/20音分，滑音开关使用150 ms；详细数值仍可在上位机修改。
同手滑音启用后按单旋律过渡；左手和弦模式不启用左手滑音。
模式0和2不依赖PC心跳，关上位机不会自动停止脱机演奏；请使用KEY2或编码器停止。
本轮参数不保存到Flash，掉电恢复默认；默认低音量，首次从低音量试音。

五、持续时间的准确含义
“按键保持”从声部实际开始生成样本计时，到点松键；之后还有释音尾巴。
“自然衰减”以钢琴C4为参考：低于C3的主体约慢4/3倍，C5及以上约快1/3；高频泛音另外逐渐变柔和。它决定音色自身如何变轻；钢琴/马林巴/拨弦可能在松键前就明显衰减。
“钢琴主体保持”只作用于钢琴；它不代表暂停波形，也不能延长已设置的按键保持时间。
改变设置不会延长已起音音符。想按新时长演奏，需要再次击发。
不要用上位机分段抓取的接收时间判断板上保持精度；准确性使用板内起音/松键采样计数验证。

六、逐音教学
内置3个16步练习：0左手、1右手、2左右交替。使用C4基准七音区、单音，无节拍评分。
先在设置选曲目，再进教学页短按；看目标手、音区编号0～6及MIDI音符。
正确的手击发正确音符后才前进；错音或错手增加错击数，不推进。转到其他模式会先静音。
共16步，完成后显示完成；再短按重新开始。曲目是乐谱事件，所有声音仍由FPGA实时合成。
LED教学仅预留语义输出(目标手/区/进度)，没有连接具体灯带，不能据此宣称完成LED教学专项。

七、电脑调试
先确认下载成功和HDMI运行，刷新实际COM口，以921600连接；通常FTDI B通道是串口，不把COM号写死。
在08页识别DUO04-LIVE 2.0后，可选择脱机/鼠标/教学、开始、归中和读取教学状态。
“开始鼠标测试”会切换到电脑模式并静音旧声音，再应用音色参数；此时IMU不会同时触发。
保留连续512/2048点抓取、32声部状态、最多四路所选声部PCM及效果后左右监测。
采集是分段的，段间有空档；48 kHz是音频采样率，不是电脑刷新率。
FFT只分析完整片段；CSV、记录和回放同旧版。旧固件仍用原音色编号和界面。
Agent新增instrument.set，例：{"mode":0,"left_timbre":0,"right_timbre":1,"left_hold_ms":1500,"run":true}。
instrument.demo始终标记模拟，不计作实物验证。切换模式后核对板上读回值。

八、声音输出与故障检查
3.5 mm口接耳机或有源音响AUX/LINE IN；有源音响自行供电。先调小音量。
2-pin端子是板载功放输出，不能接有源音响的AUX输入。
握手失败：确认新版.fs、SRAM下载成功且没掉电 → HDMI → 实际COM/921600 → 串口是否被其他程序占用 → 检查时钟/复位。
新版和旧版上位机不能同时打开同一COM。旧版握手问题尚未完成实物复现闭环；本版只宣称UART数字协议仿真通过。
有画面但没声音：模式与开始状态 → 音量 → 传感器在线/归中或鼠标击发 → 数字波形 → 模拟输出连接。
本轮不承诺已达到≤10 ms/≤5 ms，也不把数字音准/仿真试听当作真实音箱听感通过。
