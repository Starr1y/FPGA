DUO02-MOUSE 1.3（32声部调试）新增操作（2026-10-17）
1. IDE打开本目录 tanglab_duo02_mouse.gprj；本轮已综合，继续运行布局布线，检查时序后取得 impl/pnr/tanglab_duo02_mouse.fs。
2. 官方Programmer选择正确的调试器USB位置和138K C器件，SRAM下载你自己生成的新.fs；断电失效。
3. TangLab连接实际枚举的COM，921600，确认握手 DUO02-MOUSE 1.3。旧TangLab 1.3.1不是这个工程。
4. 首先测试底噪：08页独立正弦，1000Hz、−30dBFS、双声道，点击开始持续正弦。
   右侧应出现左右同相正弦；没有32声部PCM是正常的，校准源独立于演奏声部。
   左声道/右声道分别测试串音；数字峰值应约1036 PCM，RMS约733，FFT主峰附近1000Hz。
   测试电平直接控制DAC输入，演奏总音量不参与；先低音量，不一开始设置−6dBFS。
   点击停止正弦，应在约5.33ms渐变归零；不会自动恢复演奏。
5. 测试多声部：点击开始鼠标测试，按左/右音区多次；观察32按钮的音符、包络和活动状态。
   默认监测1、17，可勾选最多4路，例如1、2、17、18；未分配到的声部显示直线。
   选择“连续监测”自动512点抓取，可切2048；或切“击发同步抓取”看起音，不能同时启用。
6. 右侧波形面板跨页面共用；可拖动浮动、调宽、单击放大、右键游标，不用01/08来回切换。
   暂停只冻结显示；滚动历史保留段间空档。选路编号与采样一起保存，不混用旧选路。
7. 导出采样CSV和元数据JSON，或开始记录后测试并停止记录；回放可验证相同声部与校准模式。
8. 换到其他应用/断连/KEY2/通信超时会静音；恢复需重新开始。应用内浮动面板不会静音。
验证边界：数字仿真、综合和软件检查不等于板上听音/时序通过。本轮没有新.fs；不自动烧录。
以下保留完整供电、接口及排查步骤。

TangLab 鼠标音区上板测试指南（DUO02-MOUSE，2026-10-16）
交付调整：按你的要求，布局布线由你执行。本次没有提供新.fs；先打开下面的gprj运行综合＋布局布线，成功后使用impl/pnr/tanglab_duo02_mouse.fs。以下涉及根目录交付.fs的步骤，请改为使用你自己生成的位流。

一、这次测试什么
用电脑鼠标代替双手 IMU 的选区与击发。声音仍由 FPGA 的 DUO02 32 Voice、立体声和音效链路实时生成，HDMI 显示选区状态。
需要重新下载 DUO02-MOUSE 固件；原 TangLab 1.3/1.3.1 钢琴固件不能运行新页面。两套工程独立保留。
每手最多16个活动声部；音色为拨弦、贝斯、管乐、铃音、合成钢琴及原正弦预设，不是旧四声部页面的波形编号。
本次不接 IMU。数字仿真通过不等于布局布线或实物听音/HDMI已经通过；实物结果由你上板确认。

二、供电和连接
1. 先断电，摘下耳机。首轮拔掉之前的 IMU/外部杜邦线。
2. 沿用已经正常工作的 NEO Dock＋138K C 板卡供电方式。底板需开机时，长按 HDMI 旁 PWR 约2秒，确认电源灯正常。
   可按板卡原说明使用双USB 5V供电：USB-3.0补充供电，DEBUG-USB2接电脑；也可使用适配底板的12V DC电源。
   圆口电源规格、极性以板卡/原电源资料为准，不使用未知电压的PD诱骗转接线。不要把裸杜邦线接到电源输入试验。
3. 数据线必须插 DEBUG-USB2。USB-3.0不能代替它完成JTAG下载或TangLab串口传输。
4. HDMI接显示器并选正确输入源；音频接底板耳机输出，不是电脑耳机口。HDMI在此工程负责图像，不通过HDMI输出本测试声音。
5. 本工程 clk=V22，要求50MHz。若你改过板载时钟配置，先恢复50MHz；上位机显示的时钟参数不代替仪器测量。
   USB串口管脚：FPGA TX=U15，RX=V14，走板载调试器，无需另接串口线。
   音频及HDMI沿用DUO02原CST，不能用旧普通Dock接线表替换。IMU相关IO在鼠标版关闭，不连接模块。

三、SRAM下载
1. 新工程与烧录文件在 TangLab 文件夹中的 duo02-mouse-1.3-20261017 目录。
   IDE打开：tanglab_duo02_mouse.gprj；自行编译输出：impl/pnr/tanglab_duo02_mouse.fs。
   把整个工程文件夹一起复制，保留rtl里的ROM .hex、CST、SDC和impl中的process_config.json。
2. 关闭占用下载器的其他Programmer窗口。TangLab先断开串口。
3. 在官方Gowin Programmer扫描线缆，选择真实板卡所在USB位置；不要反复使用无效的location 0。
4. 扫描器件，确认GW5AST-138C / GW5AST-LV138PG484AC1/I0。选择SRAM Program，加载你编译得到的impl/pnr/tanglab_duo02_mouse.fs并执行。
   等待成功提示。SRAM断电失效；未主动写Flash时，不会永久替换原Flash工程。
5. 上电/下载后默认静音。HDMI应出现DUO02-MOUSE标识；如果显示原DUO02，核对你编译的工程、下载文件和目标板卡。
6. 本次需要你自行编译，可在本目录运行 Gowin IDE/bin/gw_sh.exe build.tcl；结果在impl/pnr/tanglab_duo02_mouse.fs。
   自行重编译后必须重新查看时序报告；根目录交付.fs不会被自动覆盖。

四、握手并开始
1. 双击TangLab.exe；刷新串口，选择插拔DEBUG-USB2时实际出现的COM。不要选com0com虚拟串口。
2. 波特率选择921600，点击“连接FPGA”。正常应显示真实FPGA及DUO02-MOUSE 1.2。
3. 进入“08 鼠标音区测试”。初次保留七音区、拨弦、标准C4、力度96、音效旁路，总音量32/256。
4. 点击“开始鼠标测试”，等“设备已接受”。此时只是允许发声，还没有击发音符。
   默认32/256=1/8输出；最大256/256=100%。先低音量再戴耳机，不直接调到最大。

五、左右选区、音色和和弦
1. 鼠标移入左侧扇区：高亮表示预选，移动本身不发声；左键按下一次击发一次。
2. 左侧对应左声道，右侧对应右声道。连续点两次应看到击发计数加2；按住不自动连发。
3. 移到扇区外或中心空白区取消预选。青色为板上确认的选区，品红闪烁表示板上已接受击发。
4. 七音区为DO RE MI FA SOL LA SI；五音区为DO RE MI SOL LA；十二音区含半音。
   标准C4为MIDI 60起，八度可选C2、C3、C4、C5。左右布局、音色、八度、力度分别可调。
5. 修改布局/音色/和弦/音效/总音量后，点击“应用音区参数”，等设备应答后再点扇区。
   配置切换会先释放旧声音、清理效果；不会把旧选区解释成新布局音符。
6. 勾选“左和弦/右旋律”：七音区左侧按调内三和弦发声；其他布局左侧按根音+4/+7半音三和弦，右侧仍单音。
7. 延迟、合唱、混响在音效下拉框选择，湿声0～255/256。先旁路核对左右隔离，再逐一开启比较。
8. “停止鼠标测试”、窗口失去操作焦点、断连均会停止发声；板端另有2秒通信超时保护。
   测试固件KEY2短按也执行全局静音；恢复必须重新点“开始鼠标测试”。原DUO02的组合按键不是本测试的启动方式。

六、波形和频谱
1. 默认勾选“击发同步抓取512点”：板内在该次起音后采集，上传后直接在鼠标页显示效果后左右波形与混音FFT。
   依次区别：已排队/已发送 → 设备接受 → 采样完整收到。发送成功不代表已经收到波形。
2. 上传繁忙时仍可以发出新声音，但新的同步抓取可能不执行；界面显示忙/跳过计数，不覆盖正在上传的片段。
   想检查每次起音时，等待上一次“采样完整收到”后再点。
3. “01 音频示波器”保留单次2048、连续512/2048、最新一段、滚动历史、独立缩放、游标与导出。
   新固件的五路依次为干声左、干声右、效果后左、效果后右、效果后左右平均混音。
4. 48kHz下512点覆盖约10.67ms，频率分辨率93.75Hz；2048点约42.67ms，分辨率23.44Hz。
   普通抓取不是起音同步抓取，击发编号记0。不要用短片段直接判断混响尾声或精确模拟输出延迟。
5. 连续抓取依然是分段、有空档的采集；串口上传保留10ms包间隔，不宣称无丢失的连续音频流。
6. 暂停绘图只冻结画面，不是停止声音。“清空波形”停止连续采集并清空画面，不改变音色参数。
7. “06 频谱分析”选择相应通道；幅相谱只用最近完整片段。相位参考片段起点，不是接口延迟。
8. 导出CSV时同名.json保存通道含义、击发编号和板上tick；历史CSV保留段编号、电脑接收时间及击发标记。
   板上tick为50MHz计数，32位会回绕；电脑接收时间不能当作传感器或模拟音频延迟。
9. “04 延迟与记录”可开始/停止记录，之后回放。回放与模拟会明确标注，不作为实物通过证据。

七、Agent可复制示例（在程序文件夹打开PowerShell）
先在“07 agent调试”开启本机接口。命令工具读取同目录.agent-session.json；这个文件含随机令牌，不要分享。
窗口因切换到终端失去焦点时会先停止，Agent可再显式开始测试。退出测试要执行duo.stop。
  .\TangLabCtl.exe status
  .\TangLabCtl.exe run duo.configure
  .\TangLabCtl.exe run duo.strike --json '{"hand":0,"zone":0,"capture":true}'
  .\TangLabCtl.exe capture-data
  .\TangLabCtl.exe spectrum 4
  .\TangLabCtl.exe run duo.stop
若PowerShell版本会改写JSON引号，保存参数到UTF-8文件，用 --file 参数文件.json。
duo.configure默认run=true、七音区、拨弦、音量32/256；完整字段见docs/DUO02鼠标协议与验证.md。
击发超时不要自动重发，以免同一音符响两次。Agent和GUI共用同一串口队列，不另开串口助手。

八、建议的首轮验收
先旁路、单手逐次击发5次，再右手5次；每次等待采样完成。保存采样CSV、元数据、记录文件和状态截图。
登记：设备版本、COM/921600、完成次数、CRC和缺包计数起止值、左右听音、HDMI预选与击发是否正确。
再试一次和弦、四音色、三类效果以及停止/KEY2保护。听音与HDMI分别标“人工确认通过/失败/未执行”。
如果手只在左区但右干声非零，保存五通道CSV；FX开启后的右声道判断需同时查看干声与效果后数据。

九、失败时按这个顺序检查
没有串口：DEBUG-USB2数据线、供电、设备管理器插拔变化；不要用虚拟COM。
Programmer找不到芯片：有效线缆位置、只开一个Programmer、供电/时钟；驱动错误单独排查。
握手版本不对：重新加载鼠标工程生成的tanglab_duo02_mouse.fs，不是旧钢琴位流。
点击无反应：确认已开始、配置已应答、没有失焦静音、鼠标在有效扇区、音量/力度非零。
有波形没声音：检查实际耳机输出、左右声道、板上音频链路；数字采样通过不等于DAC模拟输出通过。
没有采样：看采样繁忙提示、CRC/缺包、是否有另一抓取占用缓冲；等待完成后单击一次，不连点重试。
HDMI无图：输入源/线材/板卡供电，再看是否确实下载新固件；本轮未自动验证显示器兼容性。
