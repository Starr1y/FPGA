# 接线与上板指南

适用本快照 `DUO04-LIVE 2.0`，Tang Mega138K C、普通/NEO Dock对应的既有接线。工程/器件与底板版本需先核对；不能套用138K Pro或旧SPI工程的引脚。参考[Sipeed138K介绍](https://wiki.sipeed.com/hardware/zh/tang/tang-mega-138k/mega-138k.html)，针号依据既有31005底板原理图第7/19页核对。

## 1. 首轮只接板卡、音频与电脑

1. 关闭电源和音箱，拔掉板卡其他供电再改线。沿用已确认规格、极性正确的12V直流电源接DCIN9–12V；不要把100W充电器加无协议转换头当作已核实电源。
2. DEBUG-USB2接电脑，用可传数据的USB线；其他USB接口不等同于调试接口。串口选实际枚举的FTDI B通道，921600、8N1、无流控；COM12是本机记录，不是固定编号。
3. HDMI建议断电时接好，再上电并下载，先不要用热插拔作为验收；本机曾报告插拔关联的通信错误，原因尚未隔离。
4. 3.5mm立体声公对公线接有源电脑音箱AUX/LINE IN，音箱按自身规格另供电，初始音量低。板卡2-pin扬声器功放输出不能接音箱AUX。
5. 首轮不接IMU和编码器也可测试鼠标演奏、数字采样和当前HDMI演奏页；菜单切页仍需要EC11，PC虚拟编码器尚未实现。

## 2. 打开工程与SRAM下载

1. Gowin IDE打开本目录上层的 `fpga/tanglab_duo04.gprj`，顶层 `top_duo04`，器件 `GW5AST-LV138PG484AC1/I0`。50MHz参考不能随意改成27MHz。
2. 已有本次用户编译位流 `fpga/bitstream/tanglab_duo04.fs`，用SHA256与FIRMWARE.json核对。若修改RTL/约束，须自行重新综合和布线，不能继续使用旧.fs。
3. Programmer扫描实际USB Debugger A与正确JTAG位置，设备应对应138K C；选择SRAM下载与上述.fs。不要将BL616调试器固件.bin当作FPGA位流。
4. 成功后应显示新版HDMI界面，声音默认静音。SRAM下载断电失效；若断电后出现旧界面，应重新下载，而不是只重连串口。
5. 新生成结果默认位于 `fpga/impl/pnr/tanglab_duo04.fs`。检查setup/hold、时钟网络和PR1014；本次已有报告在fpga/reports，后续编译不能直接套用旧报告。

## 3. EC11五针G/V/A/B/S

适用于常见3.3V兼容编码器模块；模块若标明仅5V或内部含特殊电路，先核对其资料。裸机械触点不需要额外VCC，但带V端模块按厂家供电要求接。

| 模块端 | 板卡位置 | FPGA/含义 |
|---|---|---|
| G | J13.12 | GND |
| V | J9.1（或J9.2） | 3.3V |
| A | J13.1 | E14 / encoder_a |
| B | J13.2 | E13 / encoder_b |
| S | J13.3 | C15 / encoder_button_n，低有效 |

J13为靠PCIe一侧的SDRAM0长排针。**J13.11是5V，不是3.3V。** 本底板J9的1/2脚是3.3V，不能套用其他PMOD板的编号。按PCB1脚标志/方形焊盘确认针号，不按照片左右猜；同时接SDRAM或其他外设前排除这些GPIO被占用。
旋转选择，短按进入/确认，长按返回演奏页；方向反了断电交换A/B。当前编码器逻辑已有，无需因为接入它专门修改CST。

## 4. 两颗GY-BNO085（本版I²C）

| 模块丝印 | 左手J13/FPGA | 右手J13/FPGA |
|---|---|---|
| SCL/SCK/RX | .38 / E19 | .37 / D19 |
| SDA/MISO/TX | .40 / C18 | .39 / C19 |
| INT | .28 / E16 | .31 / E17 |
| RST | .36 / D20 | .32 / F16 |
| VCC_3V3 | 已核实3.3V，可从J9.1/2取电 | 同左 |
| GND | 共地，可接J13.12 | 同左 |

PS1=0、PS0=0选I²C，AD0=0地址0x4A，两路物理总线独立所以地址可相同。CS按模块厂家I²C接法处理，不能保留旧SPI工程把CS接F16（现在是右手RST）。检查SCL/SDA/RST的3.3V上拉，已有模块上拉时不要盲目叠加。VCC_3V3按用户已提供的小板定义供电，不把芯片内部电源引脚定义套到模块。

先单颗，再双颗；上电静止、归中、检查在线位，再选择脱机并开始。当前工程的双IMU实物集成尚未验收，接线正确不等于传感器已配置成功。

## 5. 正常现象与保存

握手显示 `DUO04-LIVE 2.0`；08页开始鼠标测试后预选/击发和声部活动变化；完整抓取应有实际点数、采样率及通道说明。HDMI/EC11/IMU分别逐项记录现象，遇错误先保存状态、日志及采样，再改一个条件复测。不要同时让其他串口工具占用该COM。

PR1014不隐藏；本次报告通过不等于外部模拟延迟或音质通过。若握手失败，依次检查SRAM是否仍为本版→供电/时钟→实际COM及占用→收到的字节/CRC→独立客户端对照，不能只凭一次成功判断驱动、RTL或HDMI已经排除。
