# DUO02-MOUSE 1.3（32声部调试）协议增量

本文件属于独立DUO02-MOUSE分支；旧四声部TangLab 1.3.1不具备这些能力。PC界面按握手名称发布duo_monitor能力。
所有帧沿用A5 5A、版本、类型、长度、序号、50MHz时间戳与CRC16，USB-UART为921600 baud。
多字节整数均小端；采样率48000Hz。命令返回原ACK及错误码：0接受、1忙、2参数错误、3拒绝。

| 类型 | 内容 |
|---|---|
| 0x36 monitor.select | 5字节：数量0～4、4个声部ID；使用的ID唯一且0～31，未使用填255。下次采集生效。 |
| 0x37 sine.start | 8字节：启用1、DDS增量u32、峰值幅度u16、声道位图u8。频率20～10000Hz，幅度33～16423，声道1左/2右/3双。 |
| 0x38 sine.stop | 空载荷；256采样点渐变停止，不恢复鼠标演奏。 |
| 0x8B 选路元数据 | 16字节：抓取ID u16、数量u8、4声部ID、校准标志u8、DDS增量u32、幅度u16、声道u8、保留0。 |
| 0x8A 声部PCM | 与0x82相同10字节头：抓取ID u16、起点u16、总点数u16、采样率u32；后续每样本按元数据ID顺序排列N个i16。 |

原0x89元数据保持16字节，提供抓取ID、击发ID、板上首样本tick、配置版本及五通道格式。
原0x82保持五个i16通道：干声左/右、效果后左/右、效果后左右平均混音。
两种PCM帧共用抓取ID与同一个144bit RAM写入，逐样本对齐；同一次抓取的ID/点数/采样率必须一致。
板端先发送0x89、0x8B，随后交替上传0x82和0x8A，每包32点，包间仍10ms。
校准源不占演奏声部；校准抓取的数量为0，无0x8A，五路中的干声左右也是校准直通信号。
上位机只在五路总线、选路元数据及全部预期声部样本收齐后原子发布新片段；不完整则保留上一段。
配置/选路从下一次抓取冻结；板上采样tick与电脑收到完整片段的时间分别保存，不能混为精确连续采集。

0x88状态格式4，共208字节，前192字节兼容格式3：
- 192校准模式、193校准启用、194～197 DDS增量、198～199幅度、200声道。
- 201选路数量、202～205声部ID、206校准源仍在输出/渐变、207保留。
- 原84～115为32音符，116～179为32个u16包络，32～35为活动位图。

独立校准使用1024点正弦表及32bit相位、16bit幅度、256点启停渐变，不经过32声部、ADSR、效果或响度补偿。
数字幅度与FFT不能当作模拟底噪实测。帧CRC通过也不等于器件布局布线或实际听音通过。
