TangLab 使用说明（Windows 10/11，64 位）
版本：2026-09-22 游标与幅相谱版

【一分钟体验】
解压整个 TangLab 文件夹，双击 TangLab.exe → 模拟演示 → 看五路波形。
声部与包络页修改参数后点击“应用四个声部”。模拟演示是软件合成，不是实测。
频谱分析页选择某个声部，查看幅度谱、相位谱。关闭软件再打开不会丢失已保存记录。

【1 连接板卡和下载】
适用 Tang Mega 138K 普通 Dock、C 版本；其他板型不要直接下载本工程。
连接板上 USB JTAG/UART 调试 USB，不能用其他 USB 接口代替；按官方说明供电。
安装板卡驱动及 Gowin EDA。用官方 Programmer 扫描 JTAG，选择 C 版本器件
GW5AST-LV138PG484AC1/I0，加载 fpga/bitstream/tanglab.fs，初次用 SRAM 下载。
SRAM 下载断电失效。也可重新编译 fpga/tanglab.gprj，下载 fpga/impl/pnr/tanglab.fs。
工程按 MS5351 输出 50 MHz 编译，必须确认实际板卡时钟为 50 MHz；错误时钟会影响频率和计时。
上位机刷新串口，选择板卡 COM 后连接 FPGA，等待“握手成功”。通信为 921600 baud。
com0com 为虚拟串口，不是板卡。断开按钮会断开连接并停止记录。
固件上电默认静音；声部页应用参数后 FPGA 生成音频，通过板载 I²S 输出。
从 Dock 音频输出接耳机/音箱，初次调低音量。PC 不承担实物音频实时生成。

【2 音频示波器】
五路依次为声部一、二、三、四、混音，横轴时间 ms，纵轴幅值 PCM。
抓取 2048 点：同步抓取每路完整样本，48 kHz 下约 42.67 ms。
立即触发：马上抓取；混音上升过零：等待混音从负变正，静音时可能一直等待。
开启包络预览：低带宽连续接收最小/最大幅值，不能用于精确采样或 FFT。
清空波形：清除当前完整采样、包络预览、快速 FFT 和幅相谱，同时停止包络预览；不会修改 FPGA 声部参数，也不会断开串口。
暂停绘图：暂停画面及幅相谱更新，不停止数据接收与记录。
分栏显示：各路独立缩放；取消后五路叠加共用坐标。
单击波形空白区域放大该路，再次单击或按“恢复全部波形”返回。
滚轮缩放，拖动平移；滚轮停在轴上可针对该轴缩放。
“重置波形缩放”自动适应当前单路或全部可见波形。
导出采样 CSV：导出最近一次完整抓取的时间和五通道样本，包络不可导出为完整采样。
下方混音 FFT 是快速预览；详细幅度、相位分析在“频谱分析”页。
峰值与 RMS 按满幅比例显示；削波计数提示混音可能因音量过大而饱和。

【3 游标和右键菜单】
默认所有游标关闭。在“游标声部”选一路，勾选“时间游标”和/或“幅值游标”。
时间游标为两条竖线：拖动后显示时间1、时间2、时间差及 1000/时间差 对应的频率。
该频率只是两游标间隔的倒数；只有两线相隔一个周期时才等于信号频率。
幅值游标为两条横线：显示幅值1、幅值2和绝对幅值差，单位 PCM。
取消勾选即可关闭。复位本路游标会把四条线移到当前视窗中，不改变开关状态。
每路位置和开关独立；分栏可同时开启多路，叠加只显示“游标声部”所选一路。
拖动游标不触发波形放大；切换布局会保留本次会话的游标设置。
右键绘图区可选择：自动适应数据、重置缩放、拖动平移/框选放大、网格、游标和导出 PNG 图片。
频谱及旧版曲线的右键菜单也为中文；游标选项仅用于五路时域波形。

【4 声部与包络】
四路分别设置频率 Hz、增益 0～1、波形（正弦/锯齿/方波/三角）、按下/发声。
起音：由静音升到峰值的时间；衰减：由峰值降到持续电平的时间；
持续电平：按键保持时的比例；释音：松键后降到静音的时间。时间单位均为 ms。
修改后点击“应用四个声部”才发送参数；取消某路发声并应用可逐路松键。
“全部松键/释音”同时关闭四路。较长释音会缓慢变安静，不是按钮无效。
默认四个频率为 375/750/1125/1500 Hz。多路高增益可能使混音削波，先调低增益。
ADSR 在 FPGA 中按采样步进量量化。模拟演示展示稳态波形，不模拟完整硬件包络时序。

【5 频谱分析】
从声部一至四或混音中选一路，分析最近一次完整采样或回放中的完整抓取。
幅度谱：汉宁窗单边 FFT，满幅正弦的峰值对应 0 dBFS。
相位谱：单位度，范围 −180°～180°，以当前抓取片段起点和余弦为参考。
余弦相位 0°，正弦为 −90°；低于峰值 60 dB 的频点隐藏相位，避免把噪声当成有效结果。
相位有 ±180° 跳变是包裹相位的正常表现，不能直接解释为 SPI/UART 延迟。
页面显示真实采样率、样本数、频率分辨率（采样率/点数），横轴覆盖 0～采样率一半。
全零输入标明“无有效信号”；包络预览无法分析，需重新完整抓取。
右键或滚轮可缩放；新抓取或切换分析声部时恢复完整频率范围。
“导出幅相谱 CSV”保存频率、幅度和相位，被隐藏的相位留空；右键可导出当前图图片。
这里只是单个抓取片段的幅相谱，没有时频瀑布图，不应把采集间隙当成连续采样。

【6 IMU 接线与测试】
务必断电改线
按你提供的模块说明，VCC_3V3 是一个供电脚，2.4～3.6 V，推荐 3.3 V。这里接 3.3 V，禁止接 5 V。
以下 J9 为普通 Dock PMOD0，编号依据随包 docs/reference/dock_31005.pdf 原理图；看清板上 1 脚标记，不要凭左右方向猜编号。

模块丝印           Dock 排针     FPGA 管脚       用途
VCC_3V3            J9-1          3V3             供电
GND                J9-3          GND             共地
SDA/MISO/TX        J9-11         P19             FPGA 接收/ SPI MISO
SCL/SCK/RX         J9-12         R19             FPGA 发送/ SPI SCK
AD0/MOSI           J9-9          T21             仅 SPI MOSI
CS                 J9-10         U21             SPI 片选
INT                J9-7          P16             中断，低有效
RST                J9-8          R17             复位，低有效
PS0（仅 SPI）      J9-5          R18             FPGA 控制 WAKE

PS1/PS0 模式选择（0 接 GND，1 接 3.3 V）：
UART-RVC：PS1=0，PS0=1；接电源、地、TX、RX、INT、RST；AD0/MOSI、CS 不接 FPGA。
UART-SHTP：PS1=1，PS0=0；接线同 UART-RVC。
SPI：PS1=1，PS0 接 J9-5，由 FPGA 在复位时拉高；表中信号全部连接。不要同时把 PS0 硬接 3.3 V。
UART 两种模式不要把 PS0 接 J9-5；切换时断电改线，上电后在上位机选择相同模式并应用，使 IMU 复位。
SPI 默认 Mode 3、1 MHz；UART-SHTP 为 3 Mbps；RVC 为 115200 baud、固定 100 Hz。
SHTP/SPI 复位后等待启动，再应用报告配置；RVC 只有姿态角和加速度，不提供陀螺仪报告。
这些 PMOD 管脚被本工程占用，不要同时连接其他扩展模块。所有外接信号采用 3.3 V 逻辑。


IMU 页：选择与接线一致的模式，点击“设置接口并复位 IMU”，等待启动。
SHTP/SPI 输入所需报告频率，点击“应用报告配置”；以返回配置和报告计数确认实际生效。
RVC 固定 100 Hz，不能配置角速度。旋转小板观察姿态，归中把当前方向作为显示零点。
显示最近的解析数据、配置结果及十六进制原始报文；原始报文本身不翻译。

【7 延迟、记录与回放】
总线传输耗时、FPGA 报文处理耗时和电脑通信往返耗时分别统计。
每次点击顶栏“通信往返测量”增加一次往返测量；它包含 USB、驱动及操作系统调度。
统计显示样本数、最小值、中位数、P95、最大值；P95 表示约 95% 样本不超过该值。
显示接收速率、报文缺失率、校验/解析错误、板上丢弃和记录队列丢弃，含义各不相同。
SPI 从中断/事务测点、RVC 从串口帧开始测起，两者不是完整传感器延迟。
每接口实测至少收集 1000 个有效报告再比较，并记录报告频率、接线、时钟和测试条件。
开始记录：自动创建 agent-results/日期-时间-随机编号/recording 文件夹，保存原始报文和会话信息。
停止记录：完成文件保存；记录错误会显示在页面中。请将软件放在可写目录。
打开回放：选择包含 metadata.json、raw.jsonl 的整个记录文件夹，不是选择单个文件。
回放按记录中的接收时间进行，不连接板卡；源标签会明确区分模拟、真实 FPGA 和回放。
导出统计 JSON：保存统计和接口条件；JSON 中保留稳定字段名供程序读取，不影响界面中文。
模拟记录只包含模拟音频抓取，不是硬件测量，也不承诺保存模拟姿态动画。

【8 Gowin 工程联动】
Gowin 安装目录：选择包含 IDE 与 Programmer 子目录的根目录，不是选择 exe。
工程位置：完整 .gprj/.gpr 文件路径，“选择工程”可浏览。
综合：编译 HDL 并生成综合结果；综合＋布局布线：生成下载文件、资源及内部时序报告。
停止本次编译：停止本工具启动的 gw_sh 进程；外部 IDE 中另行启动的编译不受此按钮控制。
打开工程编辑器：启动官方 IDE；打开下载工具：启动官方 Programmer，需要手动下载。
打开输出目录：打开工程旁的 impl；通常在 pnr 找到 .fs、资源和时序报告。
日志保留 Gowin 原始输出，周围的执行状态提示为中文；看到退出成功也应检查错误和时序报告。
软件不附带 Gowin 本体或许可证。源码及引脚约束在 fpga，预编译文件仅适用于上述板卡。

【9 旧版直连工具】
用于 USB-TTL 直接连接 IMU 的旧会话和旧记录，不是 FPGA 转发主入口。
支持 RVC/SHTP、姿态及实时曲线、软件归中、独立报告配置、记录和回放。
连接与配置页选择串口、模式、频率并应用；姿态页可勾选相对姿态及清除归中。
性能页显示接收批次间隔、解析耗时、界面提交年龄及记录状态，均非真实传感器延迟。
旧版与主窗口不要同时占用同一个串口；旧记录请在旧版入口回放。

【10 常见问题】
没有串口：检查数据线、调试 USB 接口及驱动。连接失败：关闭占用串口的其他软件。
无法握手：确认配套 FPGA 固件下载成功、时钟为 50 MHz、COM 正确。
波形不变：确认没有暂停绘图，参数已经应用；完整抓取需再次点击抓取更新。
游标不见：选对声部并开启开关，必要时“复位本路游标”；叠加只显示所选声部。
频谱没有相位：可能是静音、频点太弱或当前只有包络；先抓取有效完整样本。
编译工具不存在：把安装目录改成对方电脑的实际位置；默认 D 盘路径仅是本机示例。
EXE 缺少文件：必须保留 _internal 与全部依赖，不要只复制 EXE，也不要在 ZIP 内直接运行。
DLL 报错：重新完整解压本次分享包，避免与旧包混用。仍有问题请提供完整错误文本。

【11 分享与重建】
可将本次 TangLab-分享版.zip 发给他人，完整解压到可写目录后运行 TangLab.exe，无需 Python。
目标 Windows 10/11 64 位；这里只在当前电脑验证过，不能保证所有系统环境均已验证。
模拟演示无需板卡；硬件连接另需板卡驱动，综合/下载另需对方安装 Gowin EDA。
分享包不含个人记录、缓存、EDA 许可证；请保留源码、licenses 和第三方许可说明。
若自行压缩现有目录，先排除 recordings、agent-results、.agent-session.json 和自己的导出文件；不要发送任何个人许可证。
源码在 source，RTL 在 fpga，依赖许可在 licenses，参考资料和协议在 docs。
重建：复制 source 内容到开发目录，再复制 fpga、docs、使用说明.txt、使用说明.md、
THIRD_PARTY_NOTICES.md 到该目录；安装 Python 3.11+，执行 pip install -r requirements-lock.txt，
再执行 python build_exe.py。默认临时构建路径在 D:/codex/temp/tanglab-20260921。

【验证边界】
软件必要检查、RTL 仿真及 Gowin 内部 50 MHz 时序检查已完成；实物上板仍待验证。

【12 agent 调试与自动上板测试】
新增第 07 页。默认关闭本机接口，手动开启后只监听 127.0.0.1，端口以界面为准。
TangLabCtl.exe 是配套命令行工具，请在 PowerShell 使用，不能用双击方式代替命令参数。
GUI 保持运行，agent 不单独占用串口。界面和命令工具共用操作队列；硬件动作按应答顺序执行。
当前有长任务时，后续硬件命令会排队；需要打断时点击“取消当前命令”。
“关闭本机接口”停止服务、使会话令牌失效并请求取消任务，不会代替断电或硬件复位。
开启接口后生成 .agent-session.json。工具自动读取，无需把令牌发到聊天里，分享包也不包含它。
“复制连接信息”供本机自定义客户端使用，复制内容含令牌，请勿公开。
“打开测试结果目录”查看 agent-results；近期操作区显示阶段及错误，不包含令牌。
常用命令：TangLabCtl.exe status / ports / reports / events。
完整参数、Codex 与 Claude Code 提示词见 docs/agent调试接口说明.md。
下午上板按《两声部与SPI上板测试指南.txt》操作；SPI 测试必须下载 capture-fix-20260923/tanglab-audio-spi-j9-20260923.fs。
board-test/two-voice-spi.json 是真实测试，simulation.json 仅验证软件流程，SPI 标为未执行。
自动测试只开启 375/750 Hz 两声部、SPI 请求三类各 100 Hz 并收集各 1000 报告，结束后停止记录和松键。
数字数据、实际听音、端到端延迟是不同结论；自动报告不能替代人工试听和比赛完整验收。

波特率选择：主窗口串口旁可选择 115200～3000000 的预设波特率，默认 921600。必须与 FPGA 固件一致；选择后重新连接才生效。Agent connect 支持整数 baud 参数，status 返回实际 baud。
