# UI23 实板验证

本目录已包含算法 2 通过内部时序检查的 UI23 位流，可直接开始 SRAM 下载验证。先运行 `check_implementation.py`，核对冻结清单与哈希，选择 `bitstream/tanglab_duo04_ui23.fs`。桌面工程同时提供相同内容的 `impl/pnr/tanglab_duo04_ui23.fs`，便于 Programmer 选取；Git 仓库发布的是 `bitstream/` 版本。重建请运行 `gw_sh.exe build_selected.tcl` 并验收新报告。

当前最差 setup +0.032 ns、hold +0.126 ns；余量较小且有 PR1014 时钟路由警告。以下项目是待做的实板测试，文档未声称 HDMI、IMU、DAC 或整机延迟已经实测通过。

接线与 IO22 一致：左手 SCL E19/SDA C18/INT E16/RST D20；右手 SCL D19/SDA C19/INT E17/RST F16。两个模块地址均为 0x4A，PS1/PS0/AD0/CS 接公共 GND，供电使用已核实的 3.3V。两路 SCL/SDA 不互相并接；断电改线。

SRAM 下载新版本后，检查四页：浅色双手扇区、分组设置、金/绿/红教学反馈、左右手在线与归中卡片。当前 KEY0 归中、KEY1 换音色、KEY2 切操作手；KEY1+KEY2 切诊断；KEY0+KEY2 停止。离线模式自动初始化 IMU，没有旧版两键长按使能步骤。

分别归中两手。检查单纯转向只改变预选；真实下拍才出现短时扇区击发填充和击发音名。停止、断流或切到诊断页后，不应残留击发高亮。用五音和十二音布局检查音名间隔。

音频、真实 IMU 报告周期、外接 I²S DAC、整机延迟及功耗仍按原 IO22 的实板项目验证；UI 仿真没有代替这些测量。标准 I²S 的 C14/B13/C13 不接旧踏板或腕部开关。

## 第一次上板按此顺序操作

### 1. 确认版本和画面

先运行 `python check_implementation.py`，要求输出 `IMPLEMENTED, BOARD VALIDATION PENDING`，再核对 `FIRMWARE.json` 和所选 FS 的 SHA256。使用本目录发布的 `bitstream/tanglab_duo04_ui23.fs` 做 SRAM 下载。

应出现米白卡片、橙红/金色双手半环。屏幕上的初始在线状态和数值取自实际硬件；`preview/` 中的在线、力度等只是仿真输入，不是上板后的预设。

### 2. 先确认通信，再分别归中

短按 KEY1+KEY2 并全部松开，进入诊断页。此组合在本版用于切页，不用于启动 IMU。离线演奏模式下两路 IMU 自动初始化。

只有一个 IMU 时，先接左手这一组，只验证左手；右手显示离线属于实际接线状态。用 KEY2 短按切到左手，保持模块朝向基准方向，短按 KEY0 后松开。等左手显示归中完成或可演奏。右手接入后再独立重复。

### 3. 明确开始演奏

复位后程序默认停止，模块在线、已归中并不等于已开始演奏。用 EC11 短按打开快捷菜单，选择首项“开始或暂停”，再用 EC11 短按或 KEY0 短按确认。要求主屏状态变为演奏中。

本流程需要 EC11 的短按入口。KEY0+KEY1 打开的是完整设置，不能当成开始演奏；当前三个板载按键没有独立的“开始演奏”快捷键。若未接 EC11，应先补齐旋钮连接，再按本节操作。

### 4. 把选区与击发分开验证

| 动作 | 预期画面 |
|---|---|
| 保持基准方向，缓慢转向 | 预选扇区随方向变化；不应凭空增加一次击发 |
| 在预选方向沿模块本体负 Z 方向下拍 | 对应手的真实击发音名出现，原击发扇区短暂高亮约 150 ms |
| 下拍后迅速改变朝向 | 新的预选移动；之前的击发反馈仍绑定原音区 |
| 操作另一只手 | 另一侧独立选区和击发，当前操作手仅决定按键设置对象 |
| 离开归中后的 180° 有效范围 | 状态提示越界，不应把端点当成循环音区 |

“向下”是模块本体坐标负 Z，不一定是安装后房间的竖直向下；先核对模块坐标丝印和佩戴方向。当前采用去重力加速度或急动度判断，下拍只改变姿态而没有达到加速度条件时可能不会击发。

### 5. 检查设置和教学

在演奏页，KEY1 短按切当前手音色，KEY2 短按切当前操作手。KEY0 长按切音阶布局，检查五音、七音、十二音的扇区及音名间距。教学期间布局被锁定，应退出教学再检查布局切换。

快捷菜单第二项可切换演奏/教学；切换后重新从首项开始。只有左手模块时，先在教学设置中选左手练习，再开始。按金色目标音区下拍：正确显示绿色并推进，错误显示红色且不推进；完成 16 步后显示练习完成。KEY0 在教学页仍执行当前手归中。

### 6. 检查停止与恢复

按 KEY0+KEY2 保持约 0.1 秒触发全局停止。停止后音频和击发反馈应清除，保持停止状态，不会因松开按钮自动继续。重新开始仍使用快捷菜单首项。

单键短按建议 0.1～0.3 秒，并完全松开；KEY0/KEY2 长按约 1.5 秒后松开。组合键应有重叠按下时间，松开所有按键后再操作下一项，避免把组合误当成连续单键。EC11 长按约 0.8 秒后松开返回上层。
