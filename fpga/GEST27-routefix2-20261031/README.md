# GEST27 ROUTEFIX2 与 TangLab 2.7.2

2026-10-31开发验证包；保留仓库原工程，不作为稳定版发布。

## 下载与使用
1. 下载本目录两个ZIP。工程包解压后打开 `project/tanglab_duo04_score27_routefix2.gprj`；已有位流位于 `project/bitstream/`。
2. 上位机包必须完整解压，运行 `TangLab-曲谱识别2.7.2/TangLab.exe`，不需要Python。板卡驱动及Gowin工具另装。串口选择实际枚举出的COM，921600 baud。
3. 第09页支持选择或拖入图片/PDF，配置兼容视觉AI后转换；也可导入外部AI生成的 `.tangscore.json`。点击检查转换格式，确认音域后上传，等待提交成功后开始教学。最多2048步，每步单手单音。上传后可断开电脑；断电丢失，需要重新上传。详见程序内使用说明及曲谱上传指南。

## 实际验证与未闭环问题
8项定向RTL回归通过，包括四音色PCM对照、保持/滑音、抢占、32声部、串口曲谱教学与512点采集；2048点验证为缓存级完整顺序检查。
用户本次完成综合布局布线，日志无PR0004，位流已生成。但50MHz核心时序未通过：报告Fmax 48.348MHz，256个setup违例端点，TNS -69.140ns；hold无违例。PR1014 clk_d通用时钟布线警告仍存在。实物功能与稳定性未验收。
因此本.fs用于开发对照，不能将生成位流等同于时序通过或比赛验收通过。项目内旧阶段记录中的“未综合/无位流”以本次构建结果及真实reports为准。

不包含个人记录、会话令牌、EDA许可证和大型编译缓存。校验值见SHA256SUMS.txt。
