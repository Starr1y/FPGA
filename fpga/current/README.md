## 功能边界

- 左路以MPU物理+Y轴的水平指向选音；当前竖装定义为+X近似向上。Y轴朝天/朝地时水平航向无定义。
- KEY0会重新执行现有零偏/姿态归中，完成后的第一帧水平朝向为零点，应对应FA。需要转180°是待查异常，操作不应要求半圈反转。
- 七音区每区约25.714°，FA名义边界±12.875°，不是20°一音；5/12音布局按原代码保留。
- MPU无磁力计，水平航向仍可能漂移；本模块WHO=0x75兼容为已验证寄存器和采样行为的实验兼容，不声明芯片身份或绝对精度。
- 按钮10ms消抖，一次按下一次击发；运动不发声。必须在线、归中、数据新鲜且角度在有效范围内，整机还须启动演奏。
- 默认音量8/256，用户要求的默认80是下一版待办；不能把改后的源码配给此旧位流。
- 显示1024×600，像素49MHz，H总1312（48/96/144），V总624（3/10/11），约59.85186Hz，负极性同步；逻辑UI640×480映射并旋转180°。
- 右路仍为BNO085；双MPU不是本版配置。声音、方向、实际双手及长时间运行尚未完成本轮验收。

操作及完整排查见[接线指南](../../docs/V14接线与操作.md)。
