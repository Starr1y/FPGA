# TangLab：FPGA 姿态感知虚拟乐器

Tang Mega NEO / 138K，器件 `GW5AST-LV138PG484AC1/I0`。仓库仅维护 FPGA 工程、硬件参考、构建工具和验证材料。

## 当前冻结版本 DUO02

[Gowin 工程](fpga/duo02/tanglab_duo02.gprj)，顶层 `top_duo02`；[下载位流](fpga/bitstream/tanglab_duo02.fs)，HDMI 核对 **DUO02**。

- 两条独立 I²C，每手独立启停、归中、布局、选区、击发和表情。单颗模块先验证左手。
- KEY0 设置方向基准，前方 180° 非循环，7/5/12 音区；3° 边界滞回、越界和数据陈旧保护。
- 使用已去重力的本体负 Z 加速度 `az ≤ −2.5 m/s²` **或**急动度 `jz ≤ −80 m/s³` 独立击发，无须同时转腕；20 ms 静稳回位、100 ms 防连击。
- 两个独立 16 Voice 池，共 32 Voice；四种音色、ADSR、和弦/旋律和每手力度/Roll/Pitch 表情。
- 独立左右声道混音，左手进入左声道、右手进入右声道；延迟、分数合唱、简化混响，板端切换模式和湿声。
- PT8211 48 kHz / 16 位，效果后静音渐变；上电静音、两个 IMU 未使能。
- 双扇区 HDMI，中文提示、英文 DO RE MI FA SOL LA SI，青色预选、品红击发；演奏页隐藏姿态/通信，组合键打开诊断。

**数字检查、构建和时序已通过；本版本尚未下载或进行实物验证。** 真实双手、模拟声音、漂移、识别率、端到端延迟及长期负载仍待测。手动启停不是电源检测，没有新增限流、PGOOD 或掉电隔离。

## 接线与操作

整体断电接线，供电使用实际测得的 3.3 V，GND 共地；引脚按 NEO Rev1.4 原理图追踪。

| IMU 焊盘 | 手 0（左） | 手 1（右） |
| --- | --- | --- |
| SCL | E19，J13.38 | D19，J13.37 |
| SDA | C18，J13.40 | C19，J13.39 |
| INT | E16，J13.28 | E17，J13.31 |
| RST | D20，J13.36 | F16，J13.32 |

每颗模块 PS1、PS0、ADO、CS 接该模块共地节点；独立总线均使用地址 0x4A。D14/D15/F15 留空。**J13.11 是 5 V，不能作为模块 3.3 V。** F16 已用于第二手 RST，不能保留旧 SPI CS 接法。

| 实物按键 | 操作 |
| --- | --- |
| KEY2 短按并松开 | 切换当前操作手 |
| KEY2 长按至少 1.5 秒并松开 | 复位当前手 |
| KEY0 短按并松开 | 当前手归中 |
| KEY0 长按至少 1.5 秒并松开 | 当前手切换 7/5/12 音区 |
| KEY1 短按少于 300 ms | 当前手切换拨弦/贝斯/管乐/铃音 |
| KEY1 按住至少 300 ms | 当前手 Roll/Pitch 表情；松开停止颤音 |
| KEY1＋KEY2 短按并全部松开 | 演奏/诊断页 |
| KEY1＋KEY2 长按约两秒并全部松开 | 启停当前手 IMU |
| KEY0＋KEY2 长按约两秒并全部松开 | 静音切换 |
| KEY0＋KEY1 长按约两秒并全部松开 | 双旋律/左和弦右旋律 |
| 三键同时短按并全部松开 | 湿声设置增加一档，32～224/256 |
| 三键同时长按约两秒并全部松开 | 旁路→延迟→合唱→简化混响 |

音效参数切换先降低湿声、清除历史，再渐入。左手单颗测试只出左声道，与 DUO01 的复制左右输出不同。完整步骤：[DUO02 操作](docs/DUO02_立体声与音效接入.md)、[返回后单手验证](docs/DUO02_返回后单手验证.md)、[球位与排针追踪](docs/DUO01_双手板卡接入与操作.md)。

## 验证与资源

| 资源 | 已用/可用 |
| --- | --- |
| Logic | 49437/138240（35.8%） |
| Register | 21989/139095 |
| BSRAM | 74/340 |
| DSP | 83/298 |

setup/hold 违例为零，核心/像素 Fmax **50.026/26.542 MHz**（约束 50/25 MHz）。核心余量约 **0.052%**，非常小，改动或换工具后必须重新检查。PR1014 通用时钟路由告警保留。

首次算法 2 布线在“0 未布通”处异常退出，没有位流。保留本地失败证据后，算法 1 重建成功；首次异常根因仍未确定。冻结位流 SHA256：`2875c715b1bab84e3e427295e7fe4742cd5c297e43b7fafd92e15d2b79409e13`。

- 2048 个音符映射向量、8/32 Voice 实际左右 PCM、所有权/背压/取消/满载回收检查通过。
- 32 Voice 加默认混响、静音渐变和实际 DAC 串行字：3034 个采样、6066 个串行字，本场景无欠载或效果丢样，最大合成 369 个周期。
- 两个 100 Hz 行为 IMU 经 50 MHz / 48 kHz 板卡顶层：独立归中、负 Z 和弦/旋律、混响、静音渐变、停用隔离；解码 83449 个串行字。本场景只启用部分声部，最大合成 129 周期。
- 生产尺寸音效/DAC 检查：4800 采样延迟的左右有符号脉冲、独立历史清除、模式过渡、静音，解码 30289 个字。
- 组合键与 14 张 RTL 光栅画面通过，演奏页隐藏遥测不改变画面。

数字测试缩短启动/复位等待，原生链路中按键输出使用测试激励，物理按键语义另测；没有模拟厂商 TMDS 原语。PNG 是仿真画面，不能作为实物 HDMI、模拟声音或 ≤10 ms 端到端延迟证据。原生 640×480、约 59.52 Hz；显示器缩放不代表原生多分辨率/EDID 协商。

## 独立开发：编码器、踏板、腕部按键和菜单

[输入/参数控制](docs/外部编码器踏板与腕部按键逻辑.md)支持消抖、2/4 边沿定位、每手归中/布局、音色/尾音和共享效果参数。已接入[中文菜单绘制与帧快照](docs/参数菜单绘制与联动.md)，真实数字输入到参数和画面的 50/25 MHz 联动检查通过。

字体和数字统一文楷，坐标/百分比使用移位加法，无全屏帧缓存。组合模块未布局综合为 Register 560、LUT 1303、ALU 168、BSRAM 4、SSRAM 12、DSP 0。

**这些组件尚未接入 DUO02 主显示、音频或真实外部管脚。** 当前位流继续使用上方板载按键；独立菜单 GPRJ 仅供综合，不能单独下载到板卡。

## 构建和目录

Python 3 + Pillow，仿真使用 WSL Ubuntu/Icarus，构建使用 Gowin 1.9.12.03；仓库已提供 RTL/ROM，无 PC 上位机依赖。

```powershell
python -X utf8 fpga/tools/duo02_release.py verify
python -X utf8 fpga/tools/check_duo02_audio.py
python -X utf8 fpga/tools/check_duo02_output.py
python -X utf8 fpga/tools/check_duo02_board.py
python -X utf8 fpga/tools/duo02_release.py check
python -X utf8 fpga/tools/duo02_release.py build --gowin-shell "D:/Gowin/Gowin_V1.9.12.03_x64/IDE/bin/gw_sh.exe"
```

脚本不会下载 SRAM/Flash。重新构建不保证位流字节一致，冻结文件不覆盖为不同哈希。一次性工程/测试装配脚本不能重跑覆盖已审核源码；普通构建无需重建字体。
