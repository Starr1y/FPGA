# 外部编码器、踏板与腕部按键逻辑

2026-10-12。`fpga/controls/rtl/performance_controls.v` 与 `release_button.v` 提供输入逻辑，`instrument_menu.v` 已接入这些数字事件并管理演奏参数。独立 [参数菜单绘制与联动](参数菜单绘制与联动.md) 已连接该接口。**目前尚未接入 DUO02 顶层、TMDS、分配板卡引脚或进行实物验证。** 不需要上位机。

## 接口与行为

| 输入 | 功能输出 |
| --- | --- |
| `encoder_a`、`encoder_b` | 同步、连续稳定消抖、Gray 码方向判断；每个完整步输出 `encoder_step` 和方向 |
| `encoder_button_n` | 消抖后的短按/长按松键事件 |
| `pedal_n` | 合格按住再松开时只输出一次 `pedal_toggle`；长按不自动重复 |
| `wrist_button_n[1:0]` | 每手独立短按/长按松键事件 |
| `enabled` | 停用后丢弃正在进行的手势；再次启用须先看到稳定松键，不能把原来按住的按钮误识别成操作 |

按钮为低电平按下，未按下为高电平。输入同步器不能代替外部可靠上拉、共地和匹配电平。原理图和模块确定后再为这些输入分配球位；当前文件没有任何输出给外部 GPIO，也没有给未确认的位置分配管脚。

默认核心 50 MHz，产生 1 ms **时钟使能**，所有寄存器使用同一核心时钟。编码器默认连续稳定 2 ms；按钮默认 20 ms，短按最低 50 ms，长按 1500 ms。参数可按实物编码器和操作习惯调整，不产生额外时钟域。

`EDGES_PER_STEP` 可选择 2 或 4，适配常见编码器定位点。正向 Gray 序列为 `00 → 01 → 11 → 10 → 00`；反向相反。两位同时变化的跳步记为无效，清除未完成的部分位移；计数在 65535 饱和。单个边沿来回接触抖动不会累计成完整步。

事件每次仅保持一个核心周期。输入模块仅负责识别；菜单模块已实现以下语义，后续还需把其参数和命令接入板端合成/传感器所有权及实际显示。

## 参数菜单

旋转编码器会打开菜单，在选择状态切换项目；首次短按只打开菜单，已打开时短按松开进入/退出编辑。编辑状态旋转改变当前值。长按松开从编辑返回选择，选择状态长按关闭菜单并回到第一项，参数不恢复默认。

| 页编号 | 参数 | 调整范围 |
| --- | --- | --- |
| 0 | 当前手 | 左 / 右 |
| 1 | 当前手音色 | 拨弦 / 贝斯 / 管乐 / 铃音，边界限幅 |
| 2 | 当前手尾音 | 200 ms / 500 ms / 1.5 s |
| 3 | 共享效果 | 旁路 / 延迟 / 合唱 / 简化混响 |
| 4 | 共享湿声 | 0～255，分母 256，以 16 为步长、端点限幅 |
| 5 | 当前效果延迟 | 48～16368 个采样，步长 48；48 kHz 下约 1～341 ms |
| 6 | 当前效果反馈 | 延迟 0～192/256；混响 0～128/256；合唱固定零，步长 8 |
| 7 | 合唱深度 | 0～255 个采样，步长 16 |
| 8 | 演奏模式 | 双旋律 / 左手和弦＋右手旋律 |
| 9 | 静音 | 静音 / 发声 |
| 10 | 当前手音区布局 | 七音 / 五音 / 十二半音 |

延迟、合唱、混响分别保存延迟参数；延迟和混响分别保存反馈，不因模式切换而丢失。上电为左手、静音、旁路；两手尾音均为 500 ms。该菜单允许湿声上限 255，与 DUO02 的三键简易入口最高 224 不同，尚未合并两个入口。

踏板合格松开时切换演奏模式；同周期的踏板事件优先于编码器对模式项的编辑。短按各自腕部按钮请求该手归中，且只对已使能的 IMU 发出请求；长按松开切换该手 7/5/12 布局。长按优先于同手短按。操作当前手的音色/尾音/布局不会修改另一手，已经发声的音符仍应由现有分配器锁存其参数。

停用外部控制后忽略输入事件，隐藏菜单、退出编辑并保留参数；再次启用仍需先稳定松键。按钮事件优先于同周期旋转，避免按下旋钮时同时转动修改了隐藏项目。

## 检查范围

```powershell
python -X utf8 fpga/tools/check_performance_controls.py
```

2/4 边沿两种定位检查通过：正反转、边沿反弹/短毛刺、两位跳变及恢复、启用时脚踏已按住、长按不重复、松键只出一个事件、腕部左右所有权，以及停用后按住重新启用不遗留事件。测试已将原始 A/B 和机械按钮事件接到菜单，验证实际编码器选项/音色编辑和腕部布局变化；另一个菜单检查覆盖全部项目、上下限、各效果参数保留、按钮与踏板优先级和停用丢弃。

仿真用每个测试时钟代表一毫秒的加速使能，并缩短消抖/长按阈值；结果证明数字事件语义，不能证明真实机械抖动、转速上限、接线、电气隔离或板卡时序。证据见 `board-test/controls/validation.json`。物理输入接入仍属于任务书 T2 的未完成项。

`menu_control_core.v` 提供滤波与菜单的组合接口，便于后续接板卡。增加菜单可见性后，组合入口 Gowin 综合统计为 Register 249、LUT 528、ALU 51；这是未布局的独立模块结果，不是 DUO02 资源增量或 50 MHz 时序证明，没有分配外部引脚、生成位流或下载。综合入口为 `fpga/tools/synth_menu_controls.py`，证据见 `board-test/controls/synthesis-validation.json`。
