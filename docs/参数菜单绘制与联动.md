# 参数菜单绘制与联动

2026-10-12。`fpga/controls_display/rtl/menu_panel.v` 是参数菜单绘制模块，`menu_display_core.v` 已将实际输入滤波、参数控制、帧快照和绘制连接。**尚未接入 DUO02 板卡顶层、TMDS 或外部管脚，不能单独作为可下载板卡固件。**

## 界面和操作

延续 Retro-Futuristic：深色背景、青色与品红、扫描线纹理。中文和数字都来自固定版本文楷等宽 Medium 20 px，不膨胀字形；中文 24×24 字格、26 px 前进，数字 13×24 字格。已提供 ROM，普通构建无需字体 TTF 或 PC 上位机。

菜单显示操作手、音色、尾音、效果、湿声、延迟、反馈、合唱深度、模式、静音和音区布局。当前项有色条，编辑时数值品红；合唱反馈显示“固定零”。单位明确区分百分比、毫秒、秒和采样数。

旋转会打开菜单并选择项目；首次短按只打开菜单，已打开时短按进入/退出编辑。编辑状态旋转改变寄存器参数。长按从编辑返回选择，选择状态长按关闭菜单、回到第一项。停用外部控制会隐藏菜单、退出编辑并保留参数。参数控制范围与左右手归属见 [外部控制说明](外部编码器踏板与腕部按键逻辑.md)。

这是配置视图，显示参数寄存器和目标值；它没有读取当前合成器/DAC 的实际生效状态。后续接音频时，效果过渡、输出状态和目标值应继续区分。原演奏页和姿态/通信诊断页仍需由板卡适配器与本菜单统一切换。

## 数据和时钟

`menu_control_core` 的参数在 50 MHz 核心域。已有 `video_status_cdc` 的请求/应答快照将 64 位参数保持并送入 25 MHz 像素域，只在垂直消隐捕获。`visible_pixel` 与绘制模块使用同一快照，不能用另一根独立同步的显示开关直接切画面。

| status 位 | 数据 |
| --- | --- |
| 3:0、4、5 | 页编号、编辑、当前手 |
| 6、7 | 静音、和弦模式 |
| 11:8、15:12、19:16 | 两手音色、尾音、布局，每手 2 位 |
| 21:20、29:22 | 效果、湿声 |
| 43:30、51:44、59:52 | 延迟采样、反馈、合唱深度 |
| 60 | 菜单可见 |

原生画布 640×480，预期像素时钟 25 MHz，800×525 时序约 59.52 Hz。该组件没有额外 PLL、TMDS 编码、全屏帧缓存、EDID 或原生多分辨率协商；这些仍由后续板卡显示适配完成。

延迟采样除以 48 的单位换算在消隐期间逐次减法完成，最大约 342 个时钟；十进制格式化再顺序完成。像素路径无除法器。坐标、字距和百分比用移位/加法，中文与数字 ROM 的读端带使能，不产生门控时钟。

## 已完成的检查

```powershell
python -X utf8 fpga/tools/check_performance_controls.py
python -X utf8 fpga/tools/check_menu_display.py
python -X utf8 fpga/tools/check_menu_bridge.py
python -X utf8 fpga/tools/synth_menu_display.py --bridge
```

- 15 张 RTL 光栅检查：隐藏、打开、全部项目编辑、左右手、尾音/布局/静音、合唱固定反馈和数值边界。延迟、湿声、反馈、深度的十进制与独立整数参考核对；检查画面边距和各状态差异。
- 4 张联动画面：实际 50/25 MHz、非对齐相位，原始 A/B/按钮电平经过实际消抖和菜单，打开音色项、左手改为贝斯、快照可见性同步、停用隐藏并保留值；捕获不能发生在活动扫描期间。
- 绘制模块独立综合：Register 215、LUT 813、ALU 126、BSRAM 4、SSRAM 12、DSP 0。
- 输入＋菜单＋CDC＋绘制组合综合：Register 560、LUT 1303、ALU 168、BSRAM 4、SSRAM 12、DSP 0。

以上为独立组件的**未布局综合**，不是 DUO02 的资源、时序或实物显示结果。证据在 `board-test/menu-display/`；生成的 PNG 是数字仿真画面，不是板卡照片。

字体衍生名称为 TangLab Menu Bitmap，版权和 SIL OFL 1.1 见 `docs/reference/fonts/WenKai-OFL.txt`。重建字体脚本先检查 `wenkai-source.json` 的 SHA256，显式 `--regenerate-fonts` 只用于有意更新字库；不要在运行检查或构建时重写资产。

## 音频参数源接入说明

2026-10-17 已有[菜单到实际音频的独立开发核心](菜单到音频参数接入.md)。该核心输出同格式 `control_status` 目标参数以及实际生效参数/过渡标志。后续组合时应把它的目标总线经本文件的帧快照送 `menu_panel`，复用唯一 `instrument_menu`；不要同时实例化带另一份参数寄存器的 `menu_display_core`。本文件现有 4 张输入联动画面仍是独立显示组件结果，不代表新的音频核心已经与 HDMI 合并。
