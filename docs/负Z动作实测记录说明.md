# 负 Z 动作实测记录

任务书要求每人每手 100 次击打，识别率 ≥98%；非击打 100 次，误触发 ≤2 次。数字注入不能代替真人样本。

已建立空白模板 `board-test/physical-trials/负Z动作实测.csv`，目前只有表头，没有填写任何实测结果。真人测试待用户返回后进行。

每次意图动作记录人、手、位流 SHA256、唯一试次编号、`hit` 或 `nonhit`、预期音区、动作前后击发计数、实际音区、T0/T1/T2/T3 和备注。音区编号从 0 开始；七音对应 0=DO … 6=SI。无击发时也应填写实际预选音区和 T0，保留失败试次，不能删除异常数据。

一次有效击打必须计数刚好增加 1、音区正确且 T 代码有效。漏击、选错音区、一次动作连续触发多次均计失败。非击打产生的每个事件都计入误触发，不能把一次动作触发多次合并为一次误触发。不同人、手或固件版本分别统计，不合并样本凑数。复位导致计数回退的试次需另行备注并重做，工具拒绝将它当作正常差值。

运行：

```powershell
python -X utf8 fpga/tools/analyse_gesture_trials.py board-test/physical-trials/负Z动作实测.csv --output board-test/physical-trials/负Z动作统计.json
```

工具要求各组至少 100 次击打和 100 次非击打才判断验收；检查缺项、重复编号、位流哈希和计数。统计基于人工记录，不能自动证明记录真实；不会推断延迟、声学输出或两小时稳定性。

建议先做少量调试再固定阈值正式测试：静置、XY/正 Z 运动、低于阈值的动作、负 Z 下拍、反复回位。急动度是加速度变化率，上行减速也可能满足负 Z 条件；非击打集合应包含这种动作，并将实际结果完整记入 CSV。
