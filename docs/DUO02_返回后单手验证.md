# DUO02 返回后单手验证

本表尚无实物记录。使用已冻结 `fpga/bitstream/tanglab_duo02.fs`，对应清单 `board-test/duo02/firmware.json`；不要拿工作目录 `impl/` 的其他输出替代。

## 先静音验证

整体断电后，按 [DUO01 接线表](DUO01_双手板卡接入与操作.md)接一颗健康模块到手 0：SCL E19、SDA C18、INT E16、RST D20，供电使用已测得的 3.3 V，GND 共地；模块 PS1/PS0/ADO/CS 共地。右手不接、不使能。软件仍没有供电检测或掉电隔离，D15 留空。

| 步骤 | 操作 | 检查现象 | 记录 |
| --- | --- | --- | --- |
| 1 | 下载并核对 HDMI | 显示 DUO02，两手未使能、静音；焦点左手 | 待填写 |
| 2 | KEY1＋KEY2 同时长按两秒、全部松开 | 只启动左手，右手不启动；仍静音 | 待填写 |
| 3 | 短按 KEY1＋KEY2、全部松开 | 诊断页左手 PKT 增长，姿态随转动改变 | 待填写 |
| 4 | 面向正前方，稍稳后短按 KEY0 | 归中完成；数据新鲜且精度满足要求后可击发 | 待填写 |
| 5 | 返回演奏页，缓慢左右转动 | 前方 180° 非循环，青色预选，超范围禁止击发 | 待填写 |
| 6 | 模块 +Z 朝上，沿本体 −Z 做一次下拍，静稳回位 | 对应扇区短暂品红，上次音符和击发数更新；回位/防连击等待时不重复 | 待填写 |
| 7 | KEY1 持续按住至少 300 ms，慢 Roll/Pitch，再松开 | 表情状态变化，松开停止颤音；没有跨手影响 | 待填写 |
| 8 | KEY0 长按至少 1.5 秒并松开 | 7/5/12 布局切换，不显示旧布局击发闪光 | 待填写 |

慢速选区和下拍先沿用 [DUO01 单手测试表](DUO01_单手返回测试表.md) 的角度、轴方向和异常动作记录。负 Z 的条件是去重力加速度 ≤−2.5 m/s² **或**急动度 ≤−80 m/s³。向上动作的减速也可能产生负 Z 量，因此要记录动作波形，不能只凭动作名称判断误触发。

## 再验证声音和效果

以上通过后才解除静音，先低音量检查实际耳机/音频输出。单颗左手在本版本只进入左声道，右声道未发音应无该手干声；这与 DUO01 的单声道复制输出不同。

| 操作 | 检查 |
| --- | --- |
| KEY0＋KEY2 长按两秒并松开 | 静音切换；发声时下拍声音和品红击发一致，再静音后声音渐出 |
| KEY1 短按少于 300 ms | 拨弦/贝斯/管乐/铃音，从下一次新击发使用新音色 |
| 三键同时长按两秒并松开 | 旁路→延迟→合唱→简化混响；效果切换先降低湿声，过渡时标题可能短暂显示 `*` |
| 三键短按至少 50 ms、少于两秒并全部松开 | 湿声比例改变；旁路时保留设置但不使用湿声 |
| KEY0＋KEY1 长按两秒 | 双旋律/左和弦右旋律；旧音符不因切模式突然改音高 |
| KEY2 长按至少 1.5 秒 | 只复位当前手；需重新归中，旧湿声历史清除，另一手不受影响 |

当前板端三键使用固定延迟/深度/反馈预设。新外部编码器菜单虽然已单独数字验证，**没有接入这个 DUO02 位流**；当前不要新增其管脚接线。

记录声音是否正常、左右声道、异常跳区/误触发、爆音、欠载或停机。两颗模块、实际谱峰、1000 次动作至模拟输出延迟、十分钟漂移和两小时最大负载应另行采集原始数据，不由本表替代。
