# TangLab三分钟演示视频拍摄脚本

总时长严格180秒。采用真实设备画面、实际演奏声音和简短旁白。当前V14仍有无声/方向问题待确认；下面的演奏镜头需先通过拍前检查。未通过时使用文末对应替换镜头，并把视频标为“阶段演示”。

## 拍前准备

- 下载同一份V14位流并记录文件名/哈希；左MPU、右BNO按实际连接展示，不能标“双MPU”。
- 接有源音箱或板载音频输出，验证开始演奏→按键→Voice/击发反馈→真实声音；音量调到合适值并录下实际菜单数值。不要配音冒充设备发声。
- 归中原方向应是FA。若仍需转180°才能工作，先修复，或按阶段演示如实说明。
- 拍到双手传感器和双按钮才使用“双手演奏”镜头；只接左手则采用单手替换方案。
- 斜拍或锁定曝光/对焦，避开反光；先试拍屏幕，若相机与约59.85Hz刷新出现条纹，调整曝光并核查肉眼是否闪烁，不能把拍摄条纹自动判为FPGA故障。

## 180秒分镜

| 时间 | 时长 | 镜头与动作 | 旁白/字幕 |
| --- | ---: | --- | --- |
| 00:00–00:15 | 15秒 | 全景：FPGA、屏幕、传感器、按钮、音箱同框；标题“TangLab V14” | “这是TangLab姿态选音乐器。FPGA读取传感器、处理选音，实时合成声音并输出HDMI画面。” |
| 00:15–00:35 | 20秒 | 特写左MPU、右BNO和各自按钮，切到板卡；叠加简图“传感器→FPGA→音频/HDMI” | “当前版本左手使用MPU6050，右手使用BNO085。方向负责选音，外接按钮负责发声，演奏闭环不需要电脑计算。”右手未接时改说“本次先演示左路”。 |
| 00:35–00:55 | 20秒 | 拍KEY0归中，手保持方向；拍FA居中；打开快捷菜单第一项启动 | “按KEY0记录当前朝向，归中后这里是FA。再从快捷菜单启动演奏。归中与启动是两个独立操作。” |
| 00:55–01:25 | 30秒 | 手与屏幕同框，缓慢左右选至少3个音；先只移动不按，再按按钮发出对应音 | “旋转时只改变预选音，不会自动发声。按下按钮才触发所选音符，松开后可以再次击发。”保留设备原声。 |
| 01:25–01:50 | 25秒 | 已验证双手则左右交替、再叠奏；单手则播放事先练好的5～8音短句 | 双手：“两手有独立的选音和按钮，可分别演奏。”单手：“这里用左路演奏一段短句。”不能用单手镜头证明双手验收。 |
| 01:50–02:15 | 25秒 | 旋钮调音量，切换两种已验证音色；各按相同音符作A/B对比 | “旋钮可以调整音量和参数，FPGA内部合成不同音色。相同音高下可以比较音色变化。”只演示实际有声音的选项。 |
| 02:15–02:40 | 25秒 | 已验证教学则展示目标音→选错不前进→选对并按键后前进；否则展示演奏/诊断页切换与在线计数 | 教学：“教学按当前目标逐音前进。”替代：“诊断页显示连接和归中状态，便于定位通信与姿态问题。”AI图片识别若未联调，只展示流程图并标“待验收”，不伪装端到端运行。 |
| 02:40–03:00 | 20秒 | 全景结束，叠加仓库、版本号、剩余验收卡 | “V14已完成布局布线和静态时序检查。接下来补齐双手声音、长期漂移、端到端延迟和持续运行实测。工程、构建报告与任务对照已整理到仓库。” |

时长合计：15+20+20+30+25+25+25+20=180秒。

## 若当前仍无声的阶段演示替换

00:55–01:25仅展示方向选区，明确字幕“选音已验证；音频闭环排查中”；01:25–01:50展示按键松开3.3V/按下近0V及诊断反馈，说明只证明输入电平；01:50–02:15改为菜单与音量设置；其余时段不变。结尾明确“当前无声问题未解决”。这种版本是调试进展视频，不作为完整乐器验收视频。

## 拍摄后保存

保存未剪原片、最终180秒视频、烧录文件名和SHA256、接线照片、现场音量/模式、日期及实际通过项。视频仅展示功能，不能替代1000次延迟、10分钟漂移、32声部或2小时满载原始数据。
