# FAN04：表情滤波与报告连续性

## 当前功能

FAN04 在 FAN03 上修正姿态报告频率与表情滤波的一致性。保留单手 I²C、KEY0 方向基准、前方 180° 非循环选区和 7/5/12 音区，保留模块自身负 Z 线性加速度或负 Z 急动度独立击发。音频继续静音；数值表情控制可在 HDMI 上观察。

使用工程 `fpga/i2cfan04/tanglab_i2c_fan04.gprj`，顶层 `top_i2c_fan04`，位流 `fpga/bitstream/tanglab_i2c_fan04.fs`；HDMI 核对 FAN04。FAN03 位流与源码保留供追溯。

## 按键和操作

| 实物按键 | 操作 |
| --- | --- |
| KEY1＋KEY2 长按约两秒后松开 | 启停 IMU 通信 |
| KEY1＋KEY2 短按后松开 | 演奏页/诊断页切换 |
| KEY0 短按后松开 | 在线时设置方向基准；静止等待归中完成 |
| KEY0 长按约 1.5 秒后松开 | 七音/五音/十二半音切换 |
| KEY1 按住 | 表情操作：Roll 改弯音/颤音，Pitch 改明亮度；再次按住以当时姿态为新表情参考 |
| KEY1 松开 | 弯音、明亮度保持，颤音归零 |
| KEY2 长按 | IMU 复位，恢复后需要重新归中 |

实物 KEY1 对应 RTL 输入 `key2_n`（Y12），实物 KEY2 对应 `key1_n`（AB13）。按实物丝印操作。组合键由启停/页面控制消费，不应同时作为表情或复位操作。

弯音限制为 ±200 cents，颤音限制为 ±30 cents。模拟输入在 100 Hz/200 Hz 两种滤波配置下检查了 3、5、8、10 Hz 摆动和 1、2、12、15 Hz 带外摆动；当前上板配置为 **100 Hz**。这不是人体识别率或实际音色效果的测量结果。

## 改动说明

1. 原 I²C 姿态报告配置为 100 Hz，旧表情滤波按 200 Hz 使用。FAN04 使用 100 Hz 的固定系数和过零周期判定，无运行时浮点运算或除法。
2. SHTP 四元数报告序号、100 μs 时间戳及有效标志，和相应四元数一起进入姿态转换。转换忙时新报告不能覆盖正在计算的报告元数据。
3. 只有连续序号、可信时间戳及 9.5～10.5 ms 相邻间隔的姿态报告进入固定频率滤波；支持序号和时间戳自然回绕。以报告采样时间判断，批量到达的报告不会被当作高速手颤。
4. 重复、漏样、时间倒退/零间隔、不可信时间或超出间隔范围时清除表情滤波历史；停收姿态 50 ms 后停止表情激活和颤音。恢复后重新建立滤波参考，防止旧历史造成假颤音。弯音和明亮度保持；IMU 全复位才恢复默认值。

当前没有可变采样率重采样器：超出间隔范围的报告会暂停表情，需用真实 IMU 的报告时间分布确认该范围合适。未满足精度、归中、数据新鲜等演奏条件时，表情也不会激活。通信正常不等于已经满足全部演奏条件。

## 接线

I²C 接线沿用已验证的方案：VCC 为 3.3 V、GND 共地，SCL=E19、SDA=C18、INT=E16、RST=D20；PS1、PS0、ADO、CS 接模块 GND 节点，D15 留空。仅在整体断电时接线。
