# DUO01 双手板卡接入与操作

2026-10-12。新工程是 `fpga/duo01/tanglab_duo01.gprj`，顶层 `top_duo01`。**FAN04 单手静音工程和位流保留；DUO01 尚未下载或实物验证。**数字验证位流已冻结为 `fpga/bitstream/tanglab_duo01.fs`，清单为 `board-test/duo01/firmware.json`。构建和仿真结果以 `board-test/duo01/` 为准。

## 程序连接

```text
两颗 BNO085 → 两条独立 I²C → 各自原点/180°音区/负 Z 击发
                                      ↓
                                各自事件队列
                                      ↓
                       两个 16 Voice 池 → 32 Voice 合成
                                      ↓
                              48 kHz PCM → PT8211
各手真实状态 → 帧快照 CDC → 双扇区 HDMI / 按键诊断页
```

不开 PC 应用也能执行这条数字链路。当前输出仍是 **16 位单声道混音复制到左右声道**；独立立体声、效果、编码器、腕部按钮、物理踏板、频谱和 LED 教学待后续接入。按键模式切换只是当前板端入口，不代表物理踏板已完成。

## 两路接线

板卡依据：仓库 `docs/reference/Tang_Mega_NEO_Dock_138K_Rev1.4.pdf`（桌面原文件名 `Tang_Mega_NEO_Dock-138K_31004_Schematics.pdf`），图纸标题 Tang_Mega_138K_Dock(NEO)，Rev1.4，2025-03-30。

| 模块焊盘 | 手 0，界面左手 | 手 1，界面右手 |
| --- | --- | --- |
| VCC | 已确认的 3.3 V 供电点 | 同一 3.3 V 电源的可靠分支 |
| GND | 共地 | 共地 |
| SCL/SCK/RX | E19，J13.38 | D19，J13.37 |
| SDA/MISO/TX | C18，J13.40 | C19，J13.39 |
| INT | E16，J13.28 | E17，J13.31 |
| RST | D20，J13.36 | F16，J13.32 |
| PS1、PS0、ADO、CS | 分别接模块共地节点 | 分别接模块共地节点 |

两路地址均为 **0x4A**，由于总线独立而不冲突。SCL/SDA 使用模块已有上拉；用户之前测得约 4.6 kΩ。RST 由 FPGA 拉低或释放，依赖模块复位上拉。三个输出全是 **0/Z**，没有推挽高电平。

J13 是标 SDRAM0 的长排针，按板上球位丝印识别；上述 J13 数字来自原理图连接器针号，不应靠照片左右方向推算。该组引脚必须没有同时连接 SDRAM 或其他驱动设备。**J13.11 是 5V_Peripheral，不是 3.3 V；J13.12 是 GND。**供电继续使用你已用万用表确认的 3.3 V 点。

单颗验证先只接手 0，右手不使能。新工程的 F16 是第二手 RST，**第一手的 CS 不能继续连 F16**。D14、D15、F15 不再用于这个双 I²C 工程，也不要作为供电或使能跳线。

原理图引脚追踪证据：

| 信号 | SOM J1 连接点 → 网络 | Dock J13 接点 | 证据页 |
| --- | --- | --- | --- |
| E19 | J1.12 → SDRAM0_A1 | 38 | PDF 7、19 |
| C18 | J1.18 → SDRAM0_A3 | 40 | PDF 7、19 |
| E16 | J1.30 → SDRAM0_A4 | 28 | PDF 7、19 |
| D20 | J1.6 → SDRAM0_A10 | 36 | PDF 7、19 |
| D19 | J1.10 → SDRAM0_A0 | 37 | PDF 7、19 |

引脚追踪置信度高：已逐页看图、核对网络和连接器针号；尚未用两颗模块验证新接线。普通 Dock 的历史引脚表部分 SDRAM 网络名与 NEO 图纸不同，本表以 NEO 图纸为准。

## 音频接入

原理图第 7、10 页：PT8211-S 的 BCK/WS/DIN 分别接 Y17/AB17/AA16，功放 PA_EN 接 AB16。**PA_EN=1 关闭功放，PA_EN=0 开启功放。**DAC 采用 16 位 LSBJ/Japanese 格式，没有 Philips I²S 的一位延迟；WS=0 是右声道、WS=1 是左声道。

上电默认静音、PCM 为零、功放关闭。解除静音时增益用 256 个采样渐入，重新静音时渐出，约 5.33 ms。这个渐变用于控制输出幅度，不能代替模拟功放的实板爆音测量。

## 按键操作

以下名称对应板上丝印。旧工程 `key1_n` 与 `key2_n` 名称相反；DUO01 已按物理名称约束：KEY1=Y12，KEY2=AB13，KEY0=AA13。

上电默认选左手，两个 IMU 都未使能，声音静音。青色外框表示当前控制的手；更换当前手不会停止另一手演奏。

| 操作 | 功能 |
| --- | --- |
| KEY2 短按并松开 | 切换当前手：左 ↔ 右 |
| KEY0 短按并松开 | 当前手归中；等待轻微手抖容许的稳定采样 |
| KEY0 长按 ≥1.5 秒再松开 | 当前手七音 → 五音 → 十二半音 → 七音 |
| KEY1 短按 50～300 ms 并松开 | 当前手拨弦 → 贝斯 → 管乐 → 铃音 |
| KEY1 持续按住 ≥300 ms | 当前手 Roll 弯音/手颤、Pitch 明亮度；松开退出表情控制 |
| KEY2 长按 ≥1.5 秒再松开 | 仅复位当前手，归中需重新设置 |
| KEY1＋KEY2 短按 ≥50 ms、少于 2 秒并全部松开 | 演奏页 ↔ 诊断页 |
| KEY1＋KEY2 同时长按 ≥2 秒，再全部松开 | 仅启停当前手的 IMU 通信 |
| KEY0＋KEY2 同时长按 ≥2 秒，再全部松开 | 静音 ↔ 发声 |
| KEY0＋KEY1 同时长按 ≥2 秒，再全部松开 | 双旋律 ↔ 左手和弦＋右手旋律 |

组合键会消耗单键动作，松键先后略有差异也不会额外归中、换手或换音色。中断的组合按住时间不累加为两秒。已发音符保留接收击发时的音色、布局、模式和八度；新设置从下一个击发生效。

归中后相对前方 **180°** 选音，不循环。模块 **负 Z** 去重力线性加速度 ≤−2.5 m/s² **或**负 Z 急动度 ≤−80 m/s³ 独立触发；边界、精度、新鲜度和静止复位条件继续有效。两个条件的方向是模块本体坐标，不自动等于房间竖直向下。

## 界面含义

- 每手独立扇区：青色预选、洋红色短暂击发；英文唱名保留。下方显示预选和上次实际击发音。
- 状态给出未使能、离线、归中中、等待归中、越界、低精度、可击发、表情或错误停机。
- 默认页隐藏姿态/通信数字；诊断页显示偏航/俯仰/横滚（整数度）、RX/PKT/ERR/RST、报告率及精度。**通信计数和 HZ 使用十六进制，HIT 使用十进制并在 9999 截顶。**例如 HZ P0064 表示 100 Hz。
- 当前状态文案仍有简化：报告暂时陈旧时也会显示“越界”；“可击发”不细分静稳回位/防连击等待。逻辑仍会禁止陈旧数据和未回位时的击发，遇到状态疑问可看诊断页；后续版本应分开这些提示。
- 640×480 原生时序，内容水平保留 32 像素边距。显示器可缩放这个信号，但本版本没有原生多分辨率或 EDID 协商。
- WenKai Mono 中文 24×24 字格，字内按 20 像素渲染、字格间额外留空，不做字体膨胀。共用字库与扇区几何 ROM，不使用全屏帧缓存。

## 返回后的验证顺序

目前没有安排自动下载。先断电按手 0 表核对新接线，再下载确认 HDMI 的 **DUO01** 标记；保持静音，启用左手，验证在线/归中/负 Z 击发与表情。右手和解除静音分别单独验证。第二颗健康模块到位后再检查双手独立归中、停用一手、同时击发和音频。

通信使能是人为许可，**不是电源检测**；软件没有新增限流、PGOOD 或掉电隔离硬件。接触已固定也不等于模块掉电时信号完全隔离。已损坏模块不能通过这个程序恢复。
