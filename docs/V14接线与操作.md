# V14接线与操作

此表对应当前冻结V14：**左MPU6050、右BNO085**。改线断电，模块与FPGA共地，信号3.3V。J13是双排排针，数字是排针位置，D15/E19等是FPGA球位，不能混淆。

| 左MPU6050引脚 | FPGA位置 |
| --- | --- |
| VCC | 经确认的3.3V供电点 |
| GND | GND，可J13.12 |
| SCL | J13.38 / E19 |
| SDA | J13.40 / C18 |
| INT | J13.28 / E16 |
| AD0 | GND，地址0x68 |
| XDA/XCL | 不接 |

右BNO085：SCL J13.37/D19、SDA J13.39/C19、INT J13.31/E17、RST J13.32/F16；两路I²C独立。BNO模块接口模式/供电脚依实际模块确认，不套用MPU针序。当前已确认的主要实板测试为左路MPU，右路组合仍待验收。

## 发声按钮和旋钮

| 信号 | FPGA位置 | 接法 |
| --- | --- | --- |
| 左发声按钮NET1 | J13.25 / D15 / A5 | 常开按钮按下接GND |
| 右发声按钮NET2 | J13.26 / D14 / A6 | 常开按钮按下接GND |
| EC11 G | J13.12 / GND | 地 |
| EC11 A | J13.1 / E14 | 编码器A相 |
| EC11 B | J13.2 / E13 | 编码器B相 |
| EC11 S | J13.3 / C15 | 按下接地 |
| EC11 V | 仅确认支持3.3V的模块接3.3V | 裸无源编码器不需供电 |

G/V/A/B/S是旋转编码器接口，不是音频DAC。按钮内部上拉，松开约3.3V，按下近0V；带220Ω串阻的按钮板按下可能有微小压降。四脚按键需核对实物脚号和PCB封装；用户曾遇到按键地线不通，修复后输入已能拉低。

## 开始演奏（不能只归中）

1. 下载当前`.fs`到SRAM，上电先松开所有按键。板卡断电后需要重新下载。
2. 等左路在线；MPU竖装，+X向上、+Y大致水平。KEY2短按选择左手，KEY0短按并松开归中；保持朝向直到完成，原方向应为FA。
3. **在主页面短按并松开旋钮**，不要长按，打开“快捷设置”。代码中第一行标签为“开始/暂停”；默认选中第一项，**再短按旋钮确认**，发出field22启动命令并返回主页面。该项在快捷菜单，不在“全部设置→系统”里。
4. 若已深入设置，长按旋钮约0.8秒并松开，重复返回到主页面后再执行第3步。菜单内可用KEY0确认、KEY1/KEY2移动。KEY0+KEY2为全局停止。
5. 调音量至合适值。默认8/256；下一版计划80。确认演奏已启动，松开发声按钮再按下；按住不会连续重发。

若找不到第一项：记录目前菜单标题、页内条目及实际烧录文件名，不能仅凭“已归中”判断音频已启动。屏幕“可演奏”是传感器条件，`running`是整机开关，二者均须有效。

## 声音路径

板载PT8211使用已有耳机/音频输出，无需另接标准I²S线；不要混用两种串行格式。外接标准Philips I²S DAC：

| DAC信号 | FPGA位置 |
| --- | --- |
| BCK/BCLK | J13.4 / C14 |
| LRCK/WS | J13.5 / B13 |
| DIN/DATA | J13.6 / C13 |
| GND | FPGA GND |
| VCC/VIN | 按DAC实际型号确认，不猜供电电压 |

标准输出48kHz、16位双声道、BCLK=1.536MHz，无MCLK；DAC需支持此模式。线路输出接有源音箱或功放，不能默认能推动无源喇叭。J13.11是5V，不能接3.3V输入。

## 无声分段检查

| 现象 | 下一步 |
| --- | --- |
| 按下仍3.3V | 检查接地、按键脚位、NET1和J13.25连通 |
| 按下能0V但无击发 | 检查左路在线/归中/超范围/数据新鲜度，并先松键再按；电压低不等于已生成音符事件 |
| 击发计数增加但没有音频事件 | 检查整机是否启动、是否误入PC来源/教学等待、事件取消与队列 |
| 已启动且有Voice仍无声 | 检查音量、静音、板载DAC/外接DAC及音箱；用正弦校准隔离音频链路 |

目前用户最后反馈“已调高音量、按键能拉低但无声”，且尚找不到开始/暂停，故真实声音闭环仍待确认；不能把启动步骤推定为已解决。
