# FAN03：负 Z 加速度或负 Z 急动度独立击发

## 当前行为

保留 KEY0 基准方向、前方 180° 非循环选区、七音/五音/十二半音、中文 UI 与英文唱名。击发使用 IMU 自身坐标的 Z 轴，安装时 +Z 朝上；任意倾斜后的 −Z 不等于世界竖直方向。选区按相对偏航，不使用距离。

使用传感器已经扣除重力的线性加速度，令 `az = linear_z`，`jz = (az[k] - az[k-1]) / Δt`。

| 独立条件 | 阈值 |
| --- | --- |
| Z 向负半轴的加速度 | `az ≤ −2.5 m/s²` |
| Z 向负半轴的急动度 | `jz ≤ −80 m/s³` |

两条条件为 **OR**，任一成立即可击发，同时成立只计一次。FAN02 曾对急动度增加 `az ≤ −0.5 m/s²` 的附加门槛，FAN03 取消该门槛，以符合“加速度或者急动度”的独立定义。阈值排除微小抖动；不是一出现任意负数就击发。

例如 `az` 在 5 ms 内从 +1 降到 +0.5 m/s²，`jz=−100 m/s³`，虽然加速度仍在正半轴，也符合负 Z 急动度条件。反过来，负加速度向零恢复产生正急动度，不会通过急动度条件；它仍可能通过加速度条件。上行减速可能产生负加速度，不能仅凭这两项推断完整运动轨迹或真实向下速度。

诊断页 T0/T1/T2/T3 表示最近一次 IMU 击发原因：未击发/加速度/急动度/两者。离线 KEY0 按键演示属于独立演示路径，不作为 IMU 识别率证据。

## 击发门槛与回位

在线、归中完成、姿态精度至少 2/3、新鲜姿态/角速度/线性加速度、前方角度有效且无跳变告警时才接受 IMU 击发。无需最低转腕速度。低运动持续 20 ms 准备；每次击发后至少间隔 100 ms，并重新回到低运动状态才允许下一次击发。力度仍按负 Z 加速度幅度估计，急动度触发的小幅动作最低为 32。

急动度按 SH-2 实际报告时间戳计算，不使用 FPGA 收到两个报告的间隔。相邻样本序号连续、时间间隔 2～40 ms 才可使用；重复、漏样、陈旧、无时间戳、归中/重启/换布局会清除历史，第一份样本只建立基线。未加入除法、浮点或整帧缓存。

## 下载后操作

1. 需要接线时先整体断电。沿用成功的 I²C：VCC 为实际测得的 3.3 V、GND 共地；SCL=E19、SDA=C18、INT=E16、RST=D20；PS1、PS0、ADO、CS 接模块 GND 节点，D15 留空。
2. 上电后使用 `fpga/bitstream/tanglab_i2c_fan03.fs` 下载到 SRAM，HDMI 核对 **FAN03**。默认通信关闭，音频静音。
3. KEY1＋KEY2 长按约两秒再松开启用通信。在线后朝向正前方，KEY0 短按松开设置方向基准，稍稳直到归中完成。
4. 转动预选音区，测试负 Z 动作。KEY1＋KEY2 短按松开查看诊断页 T 代码和次数；KEY0 长按松开切换音阶，实物 KEY2 长按复位。

## 证据边界

数字测试覆盖负加速度、负急动度、正/零加速度时负急动度、正轴/XY/低于阈值的噪声、持续大加速度、序号/时间戳回绕和陈旧保护，另以原生 SH-2 字节检查报告时间戳。

增加 1000 次 T1/T2/T3 模拟击发、1000 组非击发输入、持续大加速度和计数/事件编号回绕检查。计时采用缩短 FPGA 时钟参数的数字模型，**不能替代真人 ≥98% 识别率、1000 次外部动作到模拟音频的 ≤10 ms 测量或真实 2 小时满负载实验**。

本次用户确认 IMU 未连接，并要求实机测试等返回后再进行。只读 JTAG 扫描曾检测到 GW5AST-138 系列、IDCODE `0x0001081B`；未执行 SRAM 下载或 Flash 写入。真实负 Z 手感、误触发和阈值仍待测试。
