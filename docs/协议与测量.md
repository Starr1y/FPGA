# TangLab v1

PC 串口 921600 baud、8N1。帧：A5 5A | version:u8=1 | type:u8 |
payload_length:u16 | sequence:u16 | FPGA_ticks:u32 | payload | CRC:u16。
所有多字节字段小端。CRC16-CCITT-FALSE，初值 FFFF、多项式 1021，
覆盖 version 到 payload 最后一个字节；CRC 自身小端。PC 最大接收 4096 字节，
FPGA 最大命令 64 字节，坏帧拒绝。每方向独立递增序号。

## 命令

|类型|负载|
|---|---|
|01 HELLO|空|
|10 VOICE|声部 u8、相位步进 u32、增益 u8、波形 u8、gate u8、A/D/S/R 各 u16|
|11 CAPTURE|触发 u8：0 立即、1 混音上升过零；固定 2048 点×5通道|
|12 MODE|0 RVC、1 UART-SHTP、2 SPI；复位 IMU|
|13 IMU_TX|SPI 为原生 SHTP 包；UART 为 7E 分隔、转义后的完整线协议|
|14 PING|空|
|15 PREVIEW|0 停止、1 开启；每 480 音频样本一组 min/max|

VOICE 相位步进 = round(频率 / 48000 × 2^32)。
波形：0 正弦、1 锯齿、2 方波、3 三角、4 钢琴（合成，需要TangLab 1.2）。钢琴复用17字节VOICE格式，按键上升沿重新起音，谐波与主体分别快速/慢速指数衰减，ADSR另作用于总体包络；丢弃达到奈奎斯特频率的第2至4谐波。
A/D/R 为每采样点的包络步进，S 为 0…65535。
TangLab 1.0 幅度采用 gain/256、env/65536 量化。
TangLab 1.1 接受17字节 VOICE：前16字节布局不变，byte5为增益低字节，byte16为高字节；增益采用 round(gain*65535)/65536。
1.1/1.2接收旧16字节包时将8位增益乘257扩展为16位。上位机在INFO固件名精确为TangLab 1.1或TangLab 1.2时启用17字节及fine_gain能力，其他固件可读、可静音，阻止非零发声。piano能力仅在TangLab 1.2启用，旧版禁止钢琴发声，静音请求仍允许。
1.1板载PT8211输出为LSBJ（模块历史名称i2s_output），每个WS电平16个BCK上升沿，发送上一字LSB后才切换WS；DAC输入为饱和混音有符号右移5位，固定-30.103dB。捕获数据仍为衰减前五路PCM。
默认静音，gate 上升重新 Attack，
gate 下降进入 Release；设置相同 gate=1 不重复触发。

## 响应

|类型|负载|
|---|---|
|80 INFO|请求序号 u16、时钟Hz u32、采样Hz u32、声部数 u8、抓取长度 u16、ASCII版本|
|81 ACK / 86 PONG|请求序号 u16、结果 u8：0 接受、1 忙可重试、2 参数/命令错误|
|82 AUDIO|抓取ID u16、起始偏移 u16、总点数 u16、采样率u32、交错排列的5通道int16|
|83 ENVELOPE|声部1…4和混音的 min:int16,max:int16，共20字节|
|84 IMU|模式u8、start/end/parsed各u32、原始接口报文|
|85 STATUS|板内溢出/错误事件合计u32、削波样本计数u32|

每个 AUDIO 包含32个采样时刻。完整性由ID、偏移、长度检查；
缺少任何块则不生成新的完整抓取、也不对残缺数据计算 FFT。
IMU 超过512字节、SHTP continuation包明确拒绝并计错；
这是调试工程支持的有界 SHTP 子集，不是完整 SH-2 协议栈。
ACK 仅表示 FPGA 接收命令，Set Feature 的成功由 IMU 返回的 FC 报告确认。

## 测量口径

- 所有板上 tick 属于同一 50 MHz 时钟域，差值按 uint32 回绕计算。
- SPI：中断下降到整包读完，包括 FPGA 响应和 SPI 移位时间。
- UART-SHTP：有效 INT 起点（无低电平 INT 时使用首字节起点）到整帧末尾。
- RVC：首字节起始位到完整19字节接收；不含内部采样和融合。
- parsed 是传输控制器封包交接点，不是姿态算法完成时间。
- PC PING 测量整条USB串口往返，不能当作单程或硬实时延迟。
- STATUS drops 是缓冲溢出、过长/错误事务等事件数量，不等于精确传感器丢帧数。
- event_mark 是参数命令接受脉冲，audio_mark 是 I²S 帧装载脉冲。
  二者仅供逻辑分析仪追踪，不能代替实际波形起音识别或DAC模拟输出测量。

I²S 使用16位双声道（同一混音复制到左右声道），平均48 kHz；
分数时钟使能将BCLK边沿量化到20 ns，这是调试级时钟，非高保真音频时钟设计。
系统时钟输入必须为50 MHz；MS5351由板载调试器配置，改变它会同时改变串口、
音调和计时比例。上板前核对调试器时钟设置，使用外部仪器校验实际频率。

## TangLab 1.3扩展（协议版本仍为1）

PIANO_CONFIG 0x16，4字节：声部u8（0～3）、保持u8（0/1）、衰减系数u16小端（1～4096，Q0.24）。默认134，约6秒降至10%。主机用round((1-exp(log(0.1)/(48000*T)))*2^24)计算，T范围0.2～30秒。有效ACK后才发VOICE；无效参数ACK code=2。保持开启且gate开启时主体满能量，谐波继续衰减；关保持不重新起音。

CAPTURE 0x11仍支持旧的一字节trigger，表示2048点；新三字节trigger u8 + points u16小端，points只支持512/2048。AUDIO既有total字段填实际点数；五路、48kHz、每包32点、CRC及10ms包间隔不变。INFO字符串TangLab 1.3用于主机能力判断。
