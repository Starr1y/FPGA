# DUO03 返回后单手验证

2026-10-17。本表为空白实测计划，尚未执行下载或测试。先只接一颗健康 IMU，右手留空且不使能。

## 先确认上电时会运行哪个程序

SRAM 下载在 FPGA 掉电后会丢失；再次上电可能运行 Flash 中的旧程序。旧 SPI/UART 与本版 I²C 的引脚用途不同。因此，不能按“先 SRAM 下载→整体断电接线→上电”就假定仍在运行 DUO03。

1. IMU 和新增外部信号先保持断开，板卡单独连接电脑。核对下载文件 `fpga/bitstream/tanglab_duo03.fs` 与发布清单，不选临时 `impl/` 文件。
2. 单板 SRAM 下载后核对 HDMI **DUO03**，两手“待使能”、静音。先用板载键验证菜单、诊断和焦点；这一步不接传感器。
3. 在接入模块前，确认冷启动来源：采用经核对的仅 JTAG 启动方式，确保配置前相关引脚状态适合接入；或经明确选择将已验证的本版写入正确启动 Flash，再以模块断开状态冷启动核对。具体模式、开关和 Flash 操作需根据实际板卡与下载器确认。本次没有改启动开关或写入 Flash。
4. 启动来源确认之后才整体断电接线。不要通过带电插拔保持 SRAM 内容。若尚不能确认冷启动程序，先停在单板 UI 检查，回来后再核对启动方式。

手动启停只是已配置逻辑对输出的门控；不是 PGOOD、限流或配置前/掉电隔离。D14/D15/F15 留空，不能用 D15 接 3V3 绕过检测。以下步骤不能消除缺少隔离时电源松动造成的反向供电风险。

## 接一颗模块，保持静音

在已核对的启动条件下，整体断电连接手 0：SCL→E19/J13.38，SDA→C18/J13.40，INT→E16/J13.28，RST→D20/J13.36。VCC 接实际测得的 3.3 V，GND 共地；PS1、PS0、ADO、CS 接模块共地节点，地址 0x4A。J13.11 是 5 V，不能作 3.3 V。具体排针追踪见[DUO01 接线](DUO01_双手板卡接入与操作.md)。

所有组合键都应一起按下、全部松开；上电先松开所有键。短按建议 80～200 ms。第一次只使用板载键，不要求外接按钮。

| 1 | 上电核对 DUO03、两手未使能、焦点左手、静音；检查模块供电与温升 | 待填写 |
| 2 | KEY1＋KEY2 长按约两秒再全部松开；只启动左手 | 待填写 |
| 3 | KEY1＋KEY2 短按切到诊断；左手 PKT 增长，姿态随转动改变 | 待填写 |

| 5 | 短按 KEY1＋KEY2 回演奏；左右慢转验证前方 180° 七区和越界保护 | 待填写 |

## 菜单与声音分开验证

KEY0＋KEY1 短按打开/关闭菜单；菜单内 KEY1 下一项/增加、KEY2 上一项/减少，KEY0 确认/退出编辑，KEY0 长按返回。菜单内不使用单键短按归中或换手；先关菜单再做演奏操作。
