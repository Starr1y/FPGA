# 姿态报告频率与表情滤波修正

2026-10-11，任务书 T2 规定慢 Roll 弯音、Pitch 明暗和 3～10 Hz 手颤。当前 I²C 主机的 `interval_for` 为 10000 µs，实际请求 100 Hz；原 `hand_expression.v` 的滤波与半周期门限以 200 Hz 为基础，直接复用会偏移识别频段。

已新增独立模块 `fpga/extensions/hand_expression_rate.v`，参数 `POSE_HZ` 支持 100/200。为两种报告率分别选择定点低通/带通系数，半周期门限和无交叉超时也随报告率调整。常数在综合时确定，不加入运行时除法或浮点。其他报告率未支持；此模块按标称均匀报告更新，实际抖动/漏报告的时间戳处理仍待后续接入。

测试在两种采样率下分别输入 1/2/3/5/8/10/12/15 Hz 的独立正弦动作：3/5/8/10 Hz 输出手颤，1/2/12/15 Hz 拒绝；检查 ±30 cent 限幅、静止清零、慢 Roll 与 Pitch 互不混用、松键保持、重新按键归零及传感器重启恢复默认值。

| 测试率 | 3 / 5 / 8 / 10 Hz 峰值（cent） | 1 / 2 / 12 / 15 Hz |
| --- | --- | --- |
| 100 Hz | 18 / 20 / 19 / 18 | 都为 0 |
| 200 Hz | 19 / 21 / 20 / 19 | 都为 0 |

完整结果及源码哈希：[表情频率检查](../board-test/expression-rate/validation.json)。复现：在项目目录运行 `python -X utf8 fpga/tools/check_expression_rate.py`。

**这是单独通过数字检查的扩展，尚未合入 FAN03，也未上板验证。**下一阶段合入时须检查实际报告率、重跑顶层表情与手颤链路，并重新构建、核对资源/时序及位流版本。
